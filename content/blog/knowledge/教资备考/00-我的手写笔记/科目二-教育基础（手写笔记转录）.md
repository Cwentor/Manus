# 模块一 教育基础知识和基本原理

## 一、教育概述（P3）（常考单选、简答）

### 1. 教育的概念

**广义**：包括学校教育、社会教育、家庭教育。凡是增进人的知识、技能，发展人的能力，影响人的思想观念的活动，都具有教育作用。

**狭义（学校教育）**：教育者**有目的、有计划、有组织**地对受教育者施加影响，促使受教育者朝着期望方向发展变化的活动。

**词源**：
- 《孟子·尽心上》——"得天下英才而教育之"，**最早提出教育一词**
- 《说文解字》——**最早对教育进行解释**（"教，上所施，下所效也""育，养子使作善也"）

### 2. 教育的构成要素

| 要素 | 地位 | 说明 |
|---|---|---|
| ① 教育者 | **主导** | 学校教师是教育者的主体；教育者还包括定教育计划、编写教科书等其他参与教育活动的人 |
| ② 受教育者 | **主体** | 教育的对象，是学习的主体 |
| ③ 教育影响 | **中介** | 教育者与受教育者的中介，包括教育内容和教育形式 |

### 3. 教育的属性

**① 社会属性**
- 永恒性——与人类社会共始终
- 历史性——不同历史时期教育性质不同
- 相对独立性——有自身规律，与社会发展不平衡（可超前或滞后）
- 生产性、民族性

**② 本质属性**
教育是**有目的地培养人的社会活动**，这是教育区别于其他现象的**根本特征**，是教育的**质的规定性**。

### 4. 教育的功能（有什么用）

| 划分 | 类型 |
|---|---|
| 按对象 | **个体**功能 / **社会**功能（单选常考） |
| 按方向 | 正向功能 / 负向功能 |
| 按呈现方式 | **显性**功能 / **隐性**功能 |

## 二、教育的产生与发展（P4–P6）

### （一）教育的起源（单选）

| 学说 | 代表人物 | 观点 | 评价 |
|---|---|---|---|
| **神话起源说** | 朱熹 | 教育由神创造，最古老 | 非科学 |
| **生物起源说** | 利托尔诺（法）、沛西·能（英） | 教育源于动物界的生存本能 | 否认了社会性，**第一个正式提出** |
| **心理起源说** | 孟禄（美） | 教育源于儿童对成人的无意识模仿 | 否认了社会性 |
| **劳动起源说** | 米丁斯基、凯洛夫（苏） | 教育起源于人类的生产劳动 | 我国主导观点 |
| 交往起源说 | 叶澜 | 教育产生于人与人之间的交往 | — |

### （二）教育的历史发展过程

**① 根本原因**：人类对自身生存和发展的需要
**② 条件**：劳动是教育产生的根本条件；语言的形成是必要条件

### 原始社会教育特点（简答）

1. 教育**与生产劳动相结合**（不分离）
2. 教育**无阶级性**
3. 教育内容和教育方法**极其简单、单一**

### 学校产生的条件（简答）

1. **社会生产力水平提高**，为学校的产生提供了必要的**物质基础**
2. **脑力与体力劳动的分工**，为学校产生提供了专门从事教育活动的**知识分子**
3. **文字的创造**和**生产生活知识的大量积累**，为其产生提供了教育的工具和手段，以及进行文字教学和传授知识的**社会需要**
4. **国家的产生**需要专门的教育机构来培养维护阶级统治的官吏和知识分子

### （三）发展（一般考单选）

**中国：**

| 朝代 | 教育特征 |
|---|---|
| **夏** | 有了**中国最早的学校教育形态**（《孟子》："夏曰校，殷曰序，周曰庠"）；尚未有文字记载和出土实物证明（待考） |
| **商周** | 形成了**学在官府、政教合一**的官学体系；形成了以**礼乐**为中心的"六艺"教育（礼乐射御书数） |
| **春秋战国** | 官学衰微、私学兴起，**私学规模最大**；"稷下学宫"是养士的缩影，是官家举办、私家主持的学校；特点是**学术自由** |
| **汉代** | 董仲舒提出"**罢黜百家，独尊儒术**"，**太学**是当时最高学府；鸿都门学是研究文学艺术的专门学校；郡国学的发展始于"文翁兴学" |
| **隋唐** | 创立**科举制**；隋唐是**中国教育史上最完整的官学体系**——"六学""二馆"（国子学、太学、四门学、律学、书学、算学；弘文馆、崇文馆），体现**等级性** |
| **宋** | 国学：程朱理学（"存天理，灭人欲"） |
| **明** | **八股文**被规定为科举文体 |
| **清** | **1905 年科举制度废除**，开始兴学堂 |

**外国：**

| 地区 | 内容 |
|---|---|
| **古印度** | 婆罗门教育：《吠陀》为主要教育内容，教师为僧侣，教义为婆罗门教；教育具有阶级性，是"宗教权威至上" |
| **古埃及** | 宫廷学校：设在宫廷里，是培养贵族子弟的地方（"以僧为师""以吏为师"）；职官学校：以吏为师、以法为教；文士学校：目的是培养能够熟练运用文字从事书写及计算工作的人 |
| **古希腊** | **雅典教育**：目的在培养有文化修养和多种才能的政治家和商人（**德智体美劳和谐发展**）；**斯巴达教育**：目的在培养忠于统治阶级的强悍军人和武士（**尚武**）。两者**政治背景不同** |
| **中世纪西欧** | **教会教育**：目的是培养僧侣和教士，内容是"**七艺**"——三科（文法、修辞、辩证法）+ 四学（算术、几何、天文、音乐）；**骑士教育**：目的是培养封建骑士，教育内容为"**骑士七技**"——骑马、击剑、打猎、投枪、游泳、下棋、吟诗。二者都**脱离生产劳动，为封建统治阶级服务** |

### （四）古代教育的特点（简答、简答）

1. 古代教育以**学校教育**取代了原始形态的教育，使学校成为教育与学习的主要场所
2. 教育具有**鲜明的阶级性**
3. 教育与**生产劳动相脱离**，教育的目的、内容都为统治阶级服务
4. 学校教育**严重脱离生产劳动**，学校教育与生产劳动、实际生活不相干，不传授生产劳动知识
5. 学校教育主要采取**个别教育**的形式，教育内容主要是一些古典人文典籍

### 近代教育（4 条）

1. 国家加强了对教育的重视和干预
2. 初等义务教育的普遍实施
3. 教育的世俗化
4. 重视教育立法

### 20 世纪以后的教育（5 条）

1. 教育的**终身化**
2. 教育的**全民化**
3. 教育的**民主化**
4. 教育的**多元化**
5. 教育技术的**现代化**

## 三、教育学的产生与发展（P7–P10）（单选为主，★★重点）

> 你的页眉标注：**教育思想** → 教育学的萌芽 / 教育现象 / 教育内容 / 教育目的 / 教育作用 / 教育教师
> 旁注：教育的功能—个体功能、社会功能；教育无目的；学在官府—学而优则仕；"其身正，不令而行"→ 教师示范作用

### （一）萌芽阶段

**1. 中国——《学记》**

- **世界上最早、最完善的教育专著**，被誉为"**教育学的雏形**"

| 观点 | 原文 |
|---|---|
| 教学相长 | "学然后知不足，教然后知困" |
| 启发性原则 | "**不愤不启，不悱不发**"（孔子，**世界第一人**） |
| 长善救失 | "教也者，长善而救其失者也" |
| 藏息相辅 | "藏焉修焉，息焉游焉" |
| 预防性原则 | "**禁于未发之谓豫**" |
| 及时施教 | "当其可之谓时" |
| 循序渐进 | "不陵节而施之谓孙" |
| 观摩学习 | "相观而善之谓摩" |
| 可接受性 | "语之而不知，虽舍之可也" |

**孔子**（《论语》）：
- 因材施教——"求也退，故进之；由也兼人，故退之"
- 启发诱导——"不愤不启，不悱不发"
- 学思结合——"学而不思则罔，思而不学则殆"
- 温故知新——"温故而知新，可以为师矣"
- 有教无类；"学而时习之""自行束脩以上，吾未尝无诲焉"
- **"有教无类"是最早的平等教育思想**

**其他：**
- 《学记》论师生关系：**"教学相长，师严道尊"**
- 教育的个体功能：**"玉不琢，不成器；人不学，不知道"**
- 墨子——"**素丝说**"（染于苍则苍，染于黄则黄），重视文史知识和实用知识
- 孟子——**性善论**，教育目的是培养"君子"，强调**教育的作用是扩充善性**
- 荀子——**性恶论**，"人之性恶，其善者伪也"，强调**教育的作用是化性起伪**
- 道家（老子、庄子）——**道法自然**，主张"绝圣弃智""绝仁弃义""**绝学无忧**"，倡导**返璞归真**，追求"无为"而达到"**小国寡民**"的理想社会

**2. 西方**

| 人物 | 著作 | 贡献 |
|---|---|---|
| **苏格拉底** | — | **产婆术**（讽刺—定义—助产术）；"**知识即美德**"；西方**最早**提出启发式教学 |
| **柏拉图** | 《理想国》 | 主张教育平等；最终目的在于促使"**灵魂转向**"；**首次提出"寓学习于游戏"** |
| **亚里士多德** | 《政治学》 | 百科全书式的学者；**首次提出"教育要遵循自然"原则** |

| 人物 | 著作 | 贡献 |
|---|---|---|
| **培根**（英） | 《论科学的价值和发展》（1623） | **首次提出"教育学"作为一门独立学科** |

## 六、教育制度（P15–P17）

### （一）教育制度的概念

- **广义**：国民教育制度
- **狭义**：**学校教育制度（学制）**，指一个国家各级各类学校的**教育系统及其管理规则**，具体规定各级各类学校的**性质、任务、目的、入学条件、修业年限**以及它们之间的**相互关系**

### （二）教育制度的历史发展

| 阶段 | 特征 |
|---|---|
| **前制度化教育** | 始于与社会同一的人类早期教育；定型的形式化教育，即实体化教育 |
| **制度化教育** | 主要指正规教育，正规教育的典型表现是学制的建立，即具有层次结构、按年龄分级的教育制度。我国定型于清末，标志是"**废科举、兴学堂**" |
| **非制度化教育** | 库姆斯："教育不应再限于学校的围墙内"（学习化社会） |

### （三）现代学校教育制度的类型（单选、简答）

1. **双轨制**——西欧（英国）
2. **单轨制**——美国
3. **分支型学制**（中间型）——苏联、中国

### （四）建立学制的依据（简答）

1. 生产力发展水平和科学技术发展状况
2. 社会政治经济制度
3. 学生身心发展规律
4. 本国学制的历史发展和外国学制的影响

### （五）我国学制的发展（★重点）

**1. 建国前**

| 学制 | 时间 | 地位 | 参照 |
|---|---|---|---|
| **壬寅学制**（《钦定学堂章程》） | 1902 | **中国第一个颁布的近代学制，但是未施行** | 日本 |
| **癸卯学制**（《奏定学堂章程》） | 1904 | **中国第一个正式实施的近代学制**；"中学为体，西学为用"；首次规定师范教育独立，师范学堂分初级、优级，确立了师范教育的独立地位 | 日本 |
| **壬子癸丑学制** | 1912–1913 | 中国第一个**资本主义**性质的学制；**第一次规定男女同校** | 日本 |
| **壬戌学制**（新学制/六三三学制） | 1922–1949 | 实现**男女教育平等**，兼顾升学和就业 | **美国** |

**2. 新中国成立后学制沿革**

| 年代 | 文件 | 主要内容 |
|---|---|---|
| 1951 | 《关于学制改革的决定》 | 标志着我国学制发展进入一个新阶段，是**新中国第一个学制** |
| 1995 | 《教育法》 | 国家实行学前教育、初等教育、中等教育、高等教育的学校教育制度，实行**九年义务教育**制度 |
| 1999 | 《关于深化教育改革，全面推进素质教育的决定》 | **第一次明确提出"终身教育"** |
| 2006 | 《义务教育法》修订 | 明确了我国义务教育全面纳入财政保障；"**六三制**"（小学六年、初中三年）、"**五四制**"（小学五年、初中四年）或九年一贯制 |

**3. 我国现行学制**

- **从层次结构上看**，分为四层次：幼儿教育、初等教育、中等教育、高等教育
- **从类别（横向结构）上看**，可分为五类：基础教育、职业技术教育、高等教育、成人教育、特殊教育
- **从教育类型上看**：我国现行学制是从单轨制发展而来的**分支型学制**

**4. 我国现行学制的改革（简答）**
1. 基本普及义务教育，重点发展农村义务教育
2. 巩固提高九年义务教育水平，推进义务教育均衡发展
3. 加快普及高中阶段教育
4. 大力发展职业教育
5. 全面提高高等教育质量
6. 加快发展继续教育，努力建设全民学习、终身学习的学习型社会
7. 关心和支持特殊教育，完善特殊教育体系，健全特殊教育保障机制

### （六）义务教育制度

**1. 概念**：义务教育是**依照法律规定**，适龄儿童和少年**必须接受**，国家、社会、学校、家庭**必须予以保证**的国民教育。

**2. 特点**：**强制性**、**免费性**、**普及性**（统一性）

**3. 法律保证**：1986 年《中华人民共和国义务教育法》规定，国家实行**九年**义务教育。

**立法宗旨：**
- 第一，发展基础教育。基础教育的发展如何，是衡量一个国家国民素质高低的重要标志
- 第二，促进社会主义物质文明建设
- 第三，促进社会主义精神文明建设

## 第二节 小学教育（P18）（考频：单选）

**概念**：小学教育即初等教育，通常指一个国家学制中的第一个阶段的教育，对象一般为 **6–12 岁**儿童。基本的普通文化常识，一般包括**基础知识和基本技能**。

**小学教育的根本任务就是打好基础。**

**小学教育的基本特点：**
1. **基础性**——社会发展层面、个体发展层面、课程内容层面
2. **义务性**——教育机会均等的、一视同仁的、普及的、免费的
3. **全面性**——基础知识、基本技能、学习愿望、思想品德和态度等多方面（**绝不能片面发展**）

### 四、小学教育的历史与现状

**（一）我国古代的小学教育**

我国的小学产生于**殷周时代**。夏曰校，殷曰序，周曰庠。

**（二）我国近现代的小学教育**（★）

| 阶段 | 内容 |
|---|---|
| **1. 近代小学教育的开端** | **1878 年，张焕纶创办上海正蒙书院内附设的小班，此为开端**；1897 年，盛宣怀创办**南洋公学**，分为四院，其中的**外院即为小学**，是我国**最早的公立小学堂** |
| **2. 清末的小学教育** | 1904 年，《奏定初等小学堂章程》规定初等小学堂为 **7 岁**儿童入学，修业年限为**五年**；同时把初等小学教育定为**义务教育** |
| **3. 中华民国的小学教育** | 1912 年后，改学堂为学校，初等小学校以 **6 岁**为入学年龄，修业年限是**四年**；1919 年，小学教育机构统称为**小学校**，入学年龄为 6 岁，修业年限是 4 年（前期）+ 2 年 |
| **4. 近现代中国小学教育的发展特征**（1840 年后） | 第一，逐步明确了小学教育为**普通教育、义务教育**的性质；第二，学制改革逐渐向世界其他国家靠近，采用修业年限为 **6 年**的"**4-2 制**"；第三，逐步明确小学教育是为培养**合格公民**打基础的教育；第四，从小学堂到小学校都有了**公立和私立**两类 |

### 五、小学的组织与运行

**（一）学校管理概述**

**1. 学校管理的概念**：学校管理是学校管理者在一定社会历史条件下，通过一定的组织机构和制度，采用一定的方法和手段，带领师生员工，充分发挥学校人、财、物、时间、空间和信息等资源的最佳整体功能，实现学校工作目标的组织活动。

**2. 学校管理的基本内容**
- 小学管理的基本内容包括：**思想品德管理**、**教学工作管理**（**核心**）、教育行政管理、总务工作管理

**3. 学校管理体制**
- 学校管理体制是学校管理组织机构和管理制度的统称，是学校管理的**根本制度**
- 对学校管理功能的实现发挥着**全局性、根本性和决定性**的作用
- **我国中小学的管理体制是校长负责制**

## 第三节 课程（P19–P23）

### 一、课程概述

**（一）词源**（单选）

**我国：**
- "课程"一词最早见于**唐代**，孔颖达在《五经正义》中为《诗经》作疏："维护课程，必君子监之，乃依法制。"但这里的"课程"与现代意义大不相同
- **朱熹**在《朱子全书·论学》中多次提及"课程"，如"宽着期限，紧着课程""小立课程，大作功夫"

**西方：**
- **斯宾塞**最早把"课程"一词用于教育学，其《什么知识最有价值》一文最早提出"课程"作为**学校教育的组织**概念

**（二）概念**
- **广义**：课程是指学校为实现培养目标而选择的教育内容及其进程的总和，包括学校所教的各门学科和有目的、有计划的各种教育活动
- **狭义**：课程是指某一门学科

**（三）关于课程的不同观点**

| 观点 | 说明 |
|---|---|
| **课程即教学科目** | 使用最普遍也是最常识化的课程定义 |
| **课程即有计划的教学活动** | 更全面地体现了课程的内涵 |
| **课程即预期的学习结果（学习经验）** | 把重点从手段转向目的 |
| **课程即学习经验** | 课程应当是学生在校通过各种活动获得的经验，把课程的重点从教材转向个人 |
| **课程即社会再生产** | 课程即文化的反映 |
| **课程即社会改造** | 课程应敢于改造一种新的社会秩序 |

**（四）制约课程的主要因素**

社会、知识、儿童是制约学校课程的三大因素：
1. 一定历史时期社会发展的要求及提供的可能（**社会需求**）
2. 一定时代人类文化及科学技术发展水平（**学科知识水平**）
3. 学生的年龄特征、知识、能力基础及其可接受性（**学习者身心发展的需求**）

> 此外，建立在不同的教育哲学理论基础上的课程理论及课程的历史，也会对课程产生重要的结构性影响。

### 二、课程的类型（★单选）

**1. 古德莱德的课程层次理论**

| 层次 | 内容 |
|---|---|
| 理想的课程 | 由一些教育研究机构、学术团体和课程专家提出的 |
| 正式的课程 | 由教育行政部门规定的 |
| 领悟的课程 | 任课教师所领悟的课程 |
| 运作的课程 | 在课堂上实际实施的课程 |
| 经验的课程 | 学生在课堂学习中实实在在体验到的东西 |

**2. 按课程任务分**

| 类型 | 内容 |
|---|---|
| **基础型课程** | 基础学力（"三基"） |
| **拓展型课程** | 开阔视野、拓展能力 |
| **研究型课程** | 探究能力 |

**3. 按呈现方式分**

| 类型 | 特点 |
|---|---|
| **显性课程** | **计划性**（内容）——关键在于内容，而非表面形式 |
| **隐性课程** | 如：校风、墙上警句（**课程表及隐性内容**），是**非计划性**的，属于**非正式课程** |

**4. 按选修要求（★）**
- **必修课程**——培养共性
- **选修课程**——完善个性

**5. 按开发管理主体分**
- 国家课程
- 地方课程
- **校本课程**（学校课程）

**6. 按组织方式分**

| 划分 | 类型 |
|---|---|
| 分科 / 综合 | 内容属性：**学科** / **活动**（经验课程） |

**相关课程**：在保留原来学科独立性的基础上，寻找两个或多个学科之间的共同点，使这些学科的教学顺序能够相互照应、相互联系、穿插进行。

**融合课程**：亦称"合科课程"，是把部分科目统合兼并于范围较广的新科目，选择对学生有意义的论题或概括的问题进行学习，如把动物学、植物学、生理学融合成为生物学。（**综合程度比相关课程更高**）

**广域课程**：合并数门相邻学科内容而形成的综合性课程，如社会研究课包括了历史、地理、经济学、社会学、政治学和人类学等。

**核心课程**：亦称"问题中心课程"，围绕一些重大的社会问题组织起来。

### 三、课程理论流派

### 四、课程目标

**（一）概念**：课程目标是依据教育宗旨和教育规律而提出的课程的具体价值和任务指标。**课程目标是教育方针和教育目的的反映。**

**（二）课程目标的基本取向**（单选）

| 取向 | 说明 |
|---|---|
| **普遍性目标** | 基于经验、哲学观或伦理观、意识形态或社会政治需要而引出的一般教育宗旨或原则 |
| **行为性目标** | 以具体的、可操作的行为的形式加以陈述的课程目标，它指明课程与教学过程结束后学生身上发生的行为变化。基本特点是**目标的精确性、具体性和可操作性** |
| **生成性目标** | 在教育情境之中随着教育过程的展开而自然生成的课程目标，是问题解决的结果，是人的经验生长的内在要求 |
| **表现性目标** | 指学生在教育情境中的种种际遇——每一个学生个性化的创造性表现 |

### 五、课程结构

**（一）课程结构的概念**
课程结构是指各部分的有机的组织与配合，即课程内容有机联系在一起的组织方式。**课程结构是课程目标转化为教育成果的纽带，是课程活动顺利开展的依据。**

**（二）合理课程结构的属性**
- **客观性**——课程结构与社会的现实要求是相关的
- **有序性**——课程内部各要素、各成分之间相互联系的有规则性
- **可转换性**——各要素、各成分之间相互联系的规律
- **可度量性**——课程内部各要素、各成分之间的联系方式可以用数量关系进行说明，一般表现为一种比例关系

### 六、课程内容

**（一）课程内容的文本表现形式**

**课程计划 → 课程标准 → 教材**（三个层次）

**1. 课程计划（曾用名：教学计划）**

- **概念**：课程计划是课程设置的**整体规划**，是国家教育主管部门制定的有关教学和教育工作的**指导性文件**
- **构成**：教学科目设置（课程设置）、学科顺序、课时分配、学年编制、学周安排。其中，**课程设置是课程计划的中心和首要问题**
- **作用**：体现了国家对学校的统一要求，是**国家学校教育的基本纲领性文件**；是编写各科课程标准的主要依据，也是学校安排教学、课程检查、衡量学校工作和质量的基本依据

**2. 课程标准（曾用名：教学大纲）——依据课程计划编制**

- **概念**：是课程计划中每门学科以纲要的形式编定的、有关学科教学内容的**指导性文件**，是课程计划的分学科展开
- **构成**：规定了学科的教学目的与任务、知识的范围、深度和结构、教学进度以及有关教学法的基本要求
- **作用**：是**编写教科书和教师进行教学的直接依据**，也是**衡量各科教学质量的重要标准**；教师应将课程标准作为检查自己教学质量的依据

**3. 教材（依据课程标准编制）**

- **概念**：教师和学生据以进行教学活动的材料，包括教科书、讲义、讲授提纲、参考书、活动指导书以及各种视听材料
- **主体**：教科书和讲义，常简称为教材
- **作用**：是教师进行教学的**主要依据**

**（二）课程内容的组织方式**

**1. 直线式与螺旋式**

| 方式 | 说明 |
|---|---|
| **直线式** | 指把一门学科的内容组织成一条在逻辑上前后相联系的直线，**前后内容基本不重复** |
| **螺旋式** | 指在不同阶段上**重复**呈现特定的教学内容，但逐渐扩大范围和加深程度，使之呈**螺旋上升**的状态 |

**2. 纵向组织和横向组织**

| 方式 | 说明 |
|---|---|
| **纵向** | 按照知识的逻辑序列，从已知到未知、从具体到抽象的先后顺序组织课程内容 |
| **横向** | 打破学科的知识界限和传统的知识体系，按照学生发展的阶段，以学生发展阶段需要探索的社会和个人的问题为依据组织课程内容，构成一个个相对独立的话题 |
