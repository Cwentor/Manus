## 第一章 历史文化素养

### 一、中国古代史

| 时期 | 必记考点 |
|---|---|
| **原始社会** | 旧石器：**元谋人**（最早，云南）、**北京人**（周口店，会用火）、山顶洞人（人工取火、磨制骨针）<br>新石器：**半坡**（黄河，粟，彩陶）、**河姆渡**（长江，水稻，干栏式建筑）、龙山（黑陶）、大汶口 |
| **夏商周** | 夏：禹建立，**启继位，世袭制代替禅让制**<br>商：**甲骨文**（成熟文字）、青铜器（**司母戊鼎**最重、四羊方尊）<br>西周：**分封制、宗法制、井田制**；国人暴动 |
| **春秋战国** | 春秋五霸：齐桓公（管仲，尊王攘夷）、晋文公、楚庄王、吴王阖闾、越王勾践<br>战国七雄：齐楚燕韩赵魏秦；**商鞅变法**（秦孝公）；**都江堰**（李冰）；百家争鸣 |
| **秦汉** | 秦：统一六国，**郡县制**，统一文字（**小篆**）、货币（半两钱）、度量衡；焚书坑儒；陈胜吴广起义<br>汉：文景之治；汉武帝（**推恩令、罢黜百家独尊儒术、张骞出使西域、丝绸之路**）；光武中兴；**蔡伦改进造纸术**；张衡地动仪；华佗麻沸散；张仲景《伤寒杂病论》 |
| **三国两晋南北朝** | **官渡之战**（曹操胜袁绍）、**赤壁之战**（孙刘联军胜曹操）、三国鼎立；**北魏孝文帝改革**（迁都洛阳、推行汉化）；淝水之战 |
| **隋唐** | 隋：开皇之治；**大运河**；**科举制**（隋炀帝设进士科）<br>唐：**贞观之治**（唐太宗）、**开元盛世**（唐玄宗）、**安史之乱**（由盛转衰）；玄奘西行、鉴真东渡、文成公主入藏 |
| **宋元** | 北宋：**杯酒释兵权**、澶渊之盟、**王安石变法**、**交子**（最早纸币）；南宋：岳飞抗金<br>**毕昇活字印刷**、指南针用于航海、火药广泛使用<br>元：成吉思汗、忽必烈建元、**行省制**、马可·波罗来华 |
| **明清** | 明：废丞相设三司、**郑和下西洋**（1405–1433，七次）、戚继光抗倭、**一条鞭法**（张居正）、李自成起义<br>清：康乾盛世、**军机处**（雍正）、闭关锁国（广州十三行）、郑成功收复台湾、雅克萨之战与《尼布楚条约》 |

### 二、中国近现代史（时间线，按顺序背）

| 年份 | 事件 |
|---|---|
| 1840 | **鸦片战争** → 《**南京条约**》（中国近代第一个不平等条约） |

| 1900 | 义和团运动 + 八国联军侵华 → 《**辛丑条约**》（中国完全沦为半殖民地半封建社会） |
| 1911 | **辛亥革命**（武昌起义，孙中山；1912 中华民国成立） |
| 1915 | **新文化运动**（陈独秀《青年杂志》，**民主与科学**） |

| 1921 | **中共一大**（上海，中国共产党成立） |
| 1927 | **南昌起义**（8月1日建军节）、**八七会议**（确定土地革命和武装反抗国民党总方针）、**秋收起义**（转井冈山）、**三湾改编**（支部建在连上） |
| 1931 | 九一八事变 |
| 1935 | **遵义会议**（确立毛泽东领导地位，党的历史上生死攸关的转折点） |
| 1936 | **西安事变**（张学良、杨虎城；抗日民族统一战线初步形成） |
| 1937 | **七七事变**（全面抗战爆发）；四大会战（淞沪、太原、徐州、武汉） |
| 1945 | 抗日战争胜利 |
| 1949 | 中华人民共和国成立 |

## 第五章 艺术素养

### 一、书法

- **字体演变**：甲骨文 → 金文 → 小篆（李斯）→ 隶书 → 楷书 → 行书 → 草书
- **楷书**：颜真卿（《多宝塔碑》）、柳公权（《玄秘塔碑》）、欧阳询（《九成宫》）——"颜筋柳骨"
- **行书三大名帖**：王羲之《**兰亭序**》（天下第一行书）、颜真卿《祭侄文稿》（第二）、苏轼《寒食帖》（第三）
- **草书**：张旭、怀素（"颠张醉素"）

### 二、绘画

**中国：** 顾恺之（《洛神赋图》《女史箴图》）｜阎立本（《步辇图》）｜**吴道子**（画圣，《送子天王图》）｜王维（文人画之祖）｜**张择端**《清明上河图》｜八大山人（朱耷）｜郑板桥（竹，扬州八怪）｜**齐白石**（虾）｜**徐悲鸿**（马）｜张大千

**西方：** 达·芬奇（《蒙娜丽莎》《最后的晚餐》）｜米开朗基罗（《大卫》、西斯廷天顶画）｜拉斐尔（《雅典学院》）｜**莫奈**《日出·印象》（印象派）｜**梵高**《向日葵》《星夜》（后印象派）｜**毕加索**《格尔尼卡》（立体主义）｜列宾《伏尔加河上的纤夫》

### 三、音乐

- **中国古代**：伯牙《高山流水》；十大名曲（《高山流水》《广陵散》《平沙落雁》《梅花三弄》《十面埋伏》《夕阳箫鼓》《渔樵问答》《胡笳十八拍》《汉宫秋月》《阳春白雪》）
