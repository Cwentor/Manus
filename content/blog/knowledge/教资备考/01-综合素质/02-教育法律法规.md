## 一、教育法律基础（低频，1题左右）

- **教育法的渊源**：宪法 → 教育法律 → 教育行政法规 → 地方性法规 → 教育规章
- **教育法律关系构成要素**：主体、客体、内容（权利义务）
- **教育法律责任类型**：行政责任、民事责任、刑事责任、违宪责任
- **教育法律救济渠道**：诉讼渠道（民事诉讼、行政诉讼、刑事诉讼）、行政渠道（行政复议、行政申诉）、仲裁、调解

## 二、《中华人民共和国教育法》（1995，2021修正）

**地位：教育领域的基本法、"母法"。**

| 考点 | 内容 |
|---|---|
| 性质 | 教育是社会主义现代化建设的基础，国家保障教育事业**优先发展** |
| 管理体制 | **国务院**教育行政部门主管全国教育工作 |
| 学校法人资格 | 学校及其他教育机构具备法人条件的，**自批准设立或者登记注册之日起**取得法人资格 |
| 学校权利（9项） | 按章程自主管理；组织实施教育教学活动；招收学生；学籍管理、奖励处分；颁发学业证书；聘任教师及职工、实施奖励处分；管理使用本单位设施经费；拒绝非法干涉 |
| 受教育者权利（5项） | 参加教育教学计划安排的各种活动、使用设施设备图书资料；获得奖学金贷学金助学金；获得公正评价、完成学业后获得相应学业证书学位证书；对处分不服提出**申诉**、对侵犯人身权财产权提出申诉或**依法提起诉讼** |
| 受教育者义务 | 遵守法律法规；遵守学生行为规范、尊敬师长、养成良好品德；努力学习完成规定的学习任务；遵守所在学校管理制度 |

**考试作弊责任（高频，2021新增）：**
- 非法获取考试试题或答案、携带或使用作弊器材资料、抄袭他人答案等 → 取消考试成绩，情节严重的**停考1–3年**
- **组织作弊、代替他人考试**、提供作弊器材、出售试题答案 → 构成犯罪的，依法追究刑事责任（**处三年以下有期徒刑或拘役**，情节严重处三年以上七年以下）

## 三、《中华人民共和国义务教育法》（1986，2006修订）

**核心：义务、免费、强制、均衡。**

| 考点 | 内容（背数字） |
|---|---|
| 年限 | **九年**义务教育 |
| 入学年龄 | 凡年满**六周岁**的儿童应当入学；条件不具备的地区可推迟到**七周岁** |
| 免费范围 | 不收**学费、杂费**；国家建立义务教育经费保障机制 |
| 管理体制 | **国务院领导**，省级政府统筹规划实施，**县级政府为主管理** |
| 均衡 | **不得分设重点班和非重点班**；不得以任何名义改变或变相改变公办学校性质 |
| 学生处分 | 对违反管理制度的学生应批评教育，**不得开除** |
| 教师禁止行为 | 不得对学生实施**体罚、变相体罚**或其他侮辱人格尊严的行为 |
| 收费 | 不得违反国家规定收取费用；不得以推销或变相推销商品、服务方式谋取利益 |
| 用人 | 不得聘用曾经因**故意犯罪被依法剥夺政治权利**或其他不适合从事义务教育工作的人 |

**法律责任（选择题常考）：** 学校有下列情形之一，由县级人民政府教育行政部门**责令限期改正；情节严重的，对直接负责的主管人员和其他直接责任人员依法给予处分**：
1. 拒绝接收具有接受普通教育能力的残疾适龄儿童、少年随班就读的
2. **分设重点班和非重点班**的
3. 违反本法规定**开除学生**的
4. 选用**未经审定**的教科书的

## 四、《中华人民共和国教师法》（1993，2009修正）

| 考点 | 内容 |
|---|---|
| 教师身份 | 履行教育教学职责的**专业人员**，承担教书育人、培养社会主义事业建设者和接班人、提高民族素质的使命 |
| 教师节 | 每年**九月十日** |
| 小学教师资格学历 | **中等师范学校毕业**及其以上学历 |
| 资格丧失 | 受到**剥夺政治权利**或**故意犯罪受到有期徒刑以上**刑事处罚的，不能取得教师资格；已取得的**丧失**教师资格 |

**教师六项权利：** ① 教育教学权（进行教育教学活动、开展教改实验）② 科研权（从事科研、学术交流、参加专业团体）③ 管理学生权（指导学生学习发展、评定品行学业成绩）④ 报酬待遇权（按时获取工资报酬、享受国家规定的福利待遇及寒暑假期带薪休假）⑤ 民主管理权（对学校教育教学管理工作提出意见和建议，通过教职工代表大会参与民主管理）⑥ 进修培训权（参加进修或其他方式的培训）

**教师六项义务：** ① 遵纪守法、为人师表 ② 贯彻国家教育方针、遵守规章制度、执行教学计划、履行教师聘约、完成教育教学工作任务 ③ 对学生进行宪法所确定的基本原则的教育和爱国主义、民族团结教育，法制教育以及思想品德、文化、科学技术教育，组织带领学生开展有益的社会活动 ④ 关心爱护全体学生、尊重学生人格、促进学生在品德智力体质等方面全面发展 ⑤ 制止有害于学生的行为或其他侵犯学生合法权益的行为，批评抵制有害于学生健康成长的现象 ⑥ 不断提高思想政治觉悟和教育教学业务水平

**解聘情形（3条，必须背）：**
1. **故意不完成**教育教学任务给教育教学工作造成损失的
2. **体罚学生，经教育不改**的
3. **品行不良、侮辱学生，影响恶劣**的

**教师申诉：** 教师对学校或其他教育机构侵犯其合法权益，或对学校作出的处理不服的，可向**教育行政部门**提出申诉，教育行政部门应当在接到申诉的**三十日内**作出处理。

## 五、《中华人民共和国未成年人保护法》（2020修订，2021.6.1施行）

**六大保护：家庭保护、学校保护、社会保护、网络保护、政府保护、司法保护。**

| 考点 | 内容 |
|---|---|
| 基本原则 | **最有利于未成年人**原则；给予未成年人特殊、优先保护；尊重人格尊严；保护隐私权和个人信息 |
| 强制报告 | 国家机关、居民委员会、村民委员会、**密切接触未成年人的单位及其工作人员**，发现未成年人身心健康受到侵害、疑似受到侵害或面临其他危险情形，应当**立即向公安、民政、教育等部门报告** |
| 学校保护 | 不得占用国家法定节假日、休息日及寒暑假期组织义务教育阶段学生**集体补课**；**幼儿园不得提前进行小学课程教育**；学校应建立学生欺凌防控制度 |
| 社会保护 | 任何组织或个人**不得招用未满十六周岁**未成年人（国家另有规定除外）；营业性娱乐场所、酒吧、网吧等不得允许未成年人进入 |
| 网络保护 | **未满十六周岁**不得注册网络直播发布者账号；网络游戏服务提供者不得在规定时间外向未成年人提供服务 |
| 政府保护 | 民政部门承担**临时监护、长期监护**职责 |
| 司法保护 | 未成年人犯罪案件**不公开审理**；讯问未成年犯罪嫌疑人应通知法定代理人到场 |

## 六、《中华人民共和国预防未成年人犯罪法》（2020修订）

**核心逻辑：分级预防、分级干预。**

**不良行为（9类，针对"苗头"）：** 吸烟、饮酒；多次旷课、逃学；无故夜不归宿、离家出走；沉迷网络；与社会上具有不良习性的人交往，组织或参加实施不良行为的团伙；进入法律法规规定未成年人不宜进入的场所；参与赌博、变相赌博或参加封建迷信、邪教等活动；阅览观看收听宣扬淫秽色情暴力恐怖极端等内容的读物音像制品或网络信息；其他不利于身心健康成长的不良行为。

**严重不良行为：** 指实施**刑法规定、因不满法定刑事责任年龄不予刑事处罚**的行为，以及其他严重危害社会的行为：结伙斗殴、追逐拦截他人、强拿硬要或任意损毁占用公私财物等寻衅滋事行为；非法携带枪支弹药或弩、匕首等管制器具；殴打辱骂恐吓或故意伤害他人身体；盗窃哄抢抢夺或故意损毁公私财物；传播淫秽读物音像制品或信息；卖淫嫖娼或进行淫秽表演；吸食注射毒品或向他人提供毒品；参与赌博赌资较大；其他严重危害社会的行为。

**干预措施梯度：**
- 不良行为 → 由**父母/监护人、学校**进行管教：训导、要求遵守特定行为规范、参加特定专题教育、心理辅导、社会服务等
- 严重不良行为 → 由**公安机关**采取矫治教育措施：予以训诫、责令赔礼道歉赔偿损失、责令具结悔过、责令定期报告活动情况、责令接受心理辅导行为矫治、责令参加社会服务活动、责令接受社会观护等
- 屡教不改/情节恶劣 → **专门学校**（专门教育）；必要时**专门矫治教育**

## 七、《学生伤害事故处理办法》（2002）

**判断口诀：看学校有没有"过错"，有错才担责。**

**学校承担责任（12种，重点记 4 种）：**
1. 校舍、场地、公共设施、设备不符合国家规定标准或有明显不安全因素
2. 安全保卫、消防、设施设备管理等安全管理制度有明显疏漏，或管理混乱、存在重大安全隐患未及时采取措施
3. 向学生提供的药品、食品、饮用水等不符合国家或行业标准
4. 组织学生参加教育教学活动或校外活动，未对学生进行安全教育、未采取必要的安全措施
5. 知道教师或其他工作人员患有不适宜担任教育教学工作的疾病但未采取必要措施
6. 违反规定组织或安排未成年学生从事不宜未成年人参加的劳动、体育运动或其他活动
7. 学生有特异体质或特定疾病不宜参加某种教育教学活动，学校知道或应当知道但未予以必要注意
8. 学生在校期间突发疾病或受到伤害，学校发现但未根据实际情况及时采取相应措施，导致不良后果加重
9. **教师或其他工作人员体罚或变相体罚学生**，或在履行职责过程中违反工作要求、操作规程、职业道德
10. 教师或其他工作人员在负有组织管理未成年学生职责期间，发现学生行为具有危险性但未进行必要的管理告诫或制止
11. 对未成年学生擅自离校等与学生人身安全直接相关的信息，学校发现或知道但未及时告知监护人，导致未成年学生脱离监护人监护发生伤害
12. 学校有未依法履行职责的其他情形

**学校无责任（6种，必考）：**
1. **不可抗力**（地震、雷击、台风、洪水等）造成的
2. 来自学校**外部**的突发性、偶发性侵害造成的
3. 学生有特异体质、特定疾病或异常心理状态，**学校不知道或难以知道**的
4. 学生**自杀、自伤**的（学校已履行相应职责，行为并无不当）
5. 在对抗性体育竞赛活动中发生意外伤害的（学校已履行相应职责，行为并无不当）
6. 其他意外因素造成的

**不在学校管理范围内（3种）：** 学生自行上下学、返校离校途中；学生自行外出或擅自离校期间；放学后、节假日或假期等学校工作时间以外，学生自行滞留学校或自行到校发生。

**事故处理程序：** 协商 → 向教育行政部门申请**调解**（受理后**60日**内完成）→ 诉讼。

## 十、法律法规选择题蒙题技巧（实在不会时用）

> 来自你存的浓缩笔记。**这是兜底手段，不是替代记忆。** 但考场上遇到没背过的条款，这几条规律命中率不低。

### 1. 一条铁律

**未成年学生不论做了什么，都不得开除。**

### 2. 学校、教师、学生"犯事"怎么处理——看关键词选责任

| 题干出现 | 选 |
|---|---|
| 不严重的 | **行政处分** |
| 看到"公安机关" | **治安管理处罚** |
| 看到"构成犯罪" | **刑事责任** |
| 看到"有人伤亡" | **刑事责任** |

### 3. 不良行为 vs 严重不良行为怎么判断

- **不良行为**：对**未成年人自身**不利（吸烟饮酒、旷课逃学、夜不归宿、沉迷网络……）
- **严重不良行为**：对**社会、对他人**有害（结伙斗殴、携带管制器具、殴打辱骂他人、盗窃、吸毒……）

### 4. 发生学生伤害，谁的责任——看"有没有过错"

| 情形 | 责任归属 |
|---|---|
| 学校、教师、工作人员有**明显过错** | **学校**承担 |
| 学生自找的、监护人有明显过错 | **学生本人或监护人** |
| 未成年学生犯了错 | **监护人赔钱** |
| 突发意外情况，学校没错 | **不承担法律责任** |
| 周末节假日自己去学校玩，学校没错 | **不承担法律责任** |
| 上学放学路上出事故，学校没错 | **不承担法律责任** |
| 学生自行离校出事故，学校没错 | **不承担法律责任** |

> **一句话总结：学校只在"有过错"时担责；不可抗力、校外侵害、学生自身原因、上下学途中，学校无责。**

## 十一、补充：**"双减"政策**要点（2025 上新增考点）

> 近年综合素质与科二都可能以时事/政策形式出现。

**1. 双减是什么**
减轻义务教育阶段**学生作业负担**和**校外培训负担**。

**2. 工作原则（4 条）**
1. 坚持**学生为本**，回应关切
2. 坚持**依法治理**，标本兼治
3. 坚持**政府主导**，多方联动
4. 坚持**统筹推进**，稳步实施

**3. 工作目标**
**一年内**有效减轻，**三年内**成效显著。

**4. 线上教学时间**
线上培训要注意保护学生视力，**每课时不超过 30 分钟**，课程间隔**不少于 10 分钟**，培训结束时间**不晚于 21 点**。

**5. 减轻作业负担的措施（5 条）**
① 健全作业管理机制 ② 确保作业总量 ③ 提高作业设计质量 ④ 加强作业完成指导 ⑤ 合理利用课余时间
