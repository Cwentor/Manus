## 一、《中小学教师职业道德规范》（2008年修订）六条

**口诀：三爱两人一终身**（爱国守法、爱岗敬业、关爱学生 + 教书育人、为人师表 + 终身学习）

| 条目 | 地位（必考对应关系） | 核心要求 |
|---|---|---|
| **爱国守法** | **基本要求** | 热爱祖国、热爱人民，拥护中国共产党领导，拥护社会主义；全面贯彻国家教育方针，自觉遵守教育法律法规，依法履行教师职责权利；不得有违背党和国家方针政策的言行 |
| **爱岗敬业** | **本质要求** | 忠诚于人民教育事业，志存高远，勤恳敬业，甘为人梯，乐于奉献；对工作高度负责，认真备课上课，认真批改作业，认真辅导学生；**不得敷衍塞责** |
| **关爱学生** | **师德的灵魂** | 关心爱护全体学生，尊重学生人格，平等公正对待学生；对学生严慈相济，做学生的良师益友；保护学生安全，关心学生健康，维护学生权益；**不讽刺、挖苦、歧视学生，不体罚或变相体罚学生** |
| **教书育人** | **天职、核心** | 遵循教育规律，实施素质教育；循循善诱，诲人不倦，因材施教；培养学生良好品行，激发学生创新精神，促进学生全面发展；**不以分数作为评价学生的唯一标准** |
| **为人师表** | **内在要求** | 坚守高尚情操，知荣明耻，严于律己，以身作则；衣着得体，语言规范，举止文明；关心集体，团结协作，尊重同事，尊重家长；作风正派，廉洁奉公；**自觉抵制有偿家教，不利用职务之便谋取私利** |
| **终身学习** | **不竭动力** | 崇尚科学精神，树立终身学习理念，拓宽知识视野，更新知识结构；潜心钻研业务，勇于探索创新，不断提高专业素养和教育教学水平 |

> **选择题最爱考的"地位对应"：**
> 基本要求=爱国守法｜本质要求=爱岗敬业｜师德的灵魂=关爱学生｜天职/核心=教书育人｜内在要求=为人师表｜不竭动力=终身学习

## 二、教师职业道德的特点

- **境界的高尚性**（高于一般职业道德）
- **意识的自觉性**
- **行为的典范性**（为人师表决定）
- **影响的深远性**（影响学生一生）
- **内容的继承性 / 发展的历史性**

## 三、教师职业行为规范

| 类别 | 要点 |
|---|---|
| **思想行为规范** | 热爱祖国人民，拥护社会主义，遵纪守法；树立正确三观；敬业奉献 |
| **教学行为规范** | 端正态度、认真备课、组织好课堂教学；因材施教、循循善诱；不迟到不拖堂；规范批改作业 |
| **人际行为规范** | 尊重学生、关心学生、严格要求、耐心辅导；尊重家长；团结同事；服从管理 |
| **仪表行为规范** | **以学生的欣赏水平为前提**；衣着整洁得体、举止端庄 |
| **语言行为规范** | 使用**普通话**；语言规范、准确、生动；不讲忌语 |

## 四、教师在教育活动中要处理好的几大关系

**① 教师与学生的关系** —— 热爱学生是**基础和根本出发点**
- 树立正确的学生观；发扬教育民主；正确处理师生矛盾；提高法制意识、保护学生合法权利；加强师德建设

**② 教师与学生家长的关系** —— 建立**平等的沟通关系**（相互信任、相互支持）
- 尊重家长；主动沟通；听取意见；不训斥指责家长；不把家长当"助教"

**③ 教师与同事的关系** —— 尊重、理解、协作
- 谦虚谨慎、尊重同志；相互学习、取长补短；维护集体荣誉

**④ 教师与教育管理者的关系** —— 尊重、支持、服从正确领导
- 服从学校大局；支持管理者工作；通过正当渠道反映意见

## 五、《中小学班主任工作规定》要点

- 每个班级配备**一名**班主任
- 班主任由学校从**班级任课教师**中选聘，担任一个班级的班主任时间一般应连续**1学年以上**
- 班主任工作量按当地教师标准课时工作量的**一半**计入基本工作量
- 班主任津贴纳入绩效工资管理
- 班主任角色：**班级工作的组织者、班集体建设的指导者、学生健康成长的引领者**，是中小学思想道德教育的骨干，是沟通家长和社区的桥梁
- 班主任的职责：教育引导学生、组织班级活动、指导学生全面发展、关注学生心理健康、协调各方教育力量

## 六、材料分析题答题模板（14分）

**题目形式：** "请从教师职业道德规范的角度，评析材料中 X 老师的行为。"

**答题结构（四步，每步都要"理论 + 材料"）：**

```
第一步（定性）：
材料中 X 老师的行为是值得肯定的 / 违背了教师职业道德规范的要求。

第二步（逐条对应，一般写 3–4 条）：
① 爱岗敬业是教师职业道德的本质要求。材料中 X 老师……，体现了……
② 关爱学生是师德的灵魂。材料中 X 老师没有因为……而……，而是……，做到了严慈相济/不体罚学生。
③ 教书育人是教师的天职。材料中 X 老师不仅传授知识，还……，做到了不以分数作为评价学生的唯一标准。
④ 为人师表是教师职业道德的内在要求。材料中 X 老师……，做到了以身作则/廉洁从教。

第三步（反向补充，若材料有不当行为）：
材料中 X 老师……的做法违背了……的要求，是不妥当的。

第四步（收尾）：
综上，教师应自觉践行"三爱两人一终身"的职业道德规范，做学生成长的引路人。
```

**常考材料类型与对应条目：**

| 材料情节 | 对应规范 |
|---|---|
| 教师收受家长礼品、有偿补课 | **为人师表**（廉洁奉公、抵制有偿家教） |
| 教师讽刺挖苦、罚站、罚抄 | **关爱学生**（不讽刺歧视、不体罚变相体罚） |
| 教师只认分数、排名次 | **教书育人**（不以分数为唯一标准） |
| 教师迟到早退、敷衍备课 | **爱岗敬业**（不得敷衍塞责） |
| 教师体罚致伤、侮辱学生 | **爱国守法** + 关爱学生（违法） |
| 教师坚持学习、参加培训 | **终身学习** |
| 教师上课接电话、衣着暴露 | **为人师表**（衣着得体、语言规范） |

> **踩分提醒：** 材料分析题 14 分，通常给 3–4 个采分点，每点 3–4 分。写满 5 条以上、条条有理论有材料，稳拿 12 分以上。
