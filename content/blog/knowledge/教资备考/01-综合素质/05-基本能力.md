## 第一节 信息处理能力（单选 4 题左右）

| 考点 | 要点 |

### 二、Excel 电子表格（考得最多）

**单元格引用（必考）：**

| 类型 | 写法 | 拖动时 |
|---|---|---|
| 相对引用 | `A1` | 行列都变 |
| 绝对引用 | `$A$1` | 行列都不变 |
| 混合引用 | `$A1` / `A$1` | 加 `$` 的那一项不变 |

**常用函数：**

| 函数 | 作用 | 示例 |
|---|---|---|
| `SUM` | 求和 | `=SUM(A1:A10)` |
| `AVERAGE` | 平均值 | `=AVERAGE(B2:B20)` |
| `MAX` / `MIN` | 最大/最小值 | `=MAX(C1:C9)` |
| `COUNT` | 统计**数字**个数 | `=COUNT(A1:A10)` |
| `COUNTA` | 统计**非空**单元格 | `=COUNTA(A1:A10)` |
| `COUNTIF` | 条件计数 | `=COUNTIF(A1:A10,">60")` |
| `SUMIF` | 条件求和 | `=SUMIF(A:A,"男",C:C)` |
| `IF` | 条件判断 | `=IF(A1>=60,"及格","不及格")` |
| `RANK` | 排名 | `=RANK(A1,$A$1:$A$10)` |
| `VLOOKUP` | 纵向查找 | `=VLOOKUP(A1,表2!A:B,2,0)` |
| `LEFT/RIGHT/MID` | 截取字符 | `=MID(A1,2,3)` |
| `TODAY` | 当前日期 | `=TODAY()` |

**图表选择：** 柱形图（比较大小）、折线图（看趋势）、饼图（看占比）、散点图（看相关性）。

### 三、PowerPoint 演示文稿

- **母版**：统一修改所有幻灯片字体、背景、占位符（视图 → 幻灯片母版）
- **动画** vs **切换**：动画作用于对象（进入/强调/退出/动作路径），切换作用于幻灯片之间
- **超链接**：可链接到本文档位置、其他文件、网页
- 放映快捷键：F5 从头放映，Shift+F5 从当前页放映，Esc 退出

## 第二节 逻辑思维能力（单选 2 题左右）

### 一、概念间关系

| 关系 | 说明 | 例子 |
|---|---|---|
| 全同 | 外延完全重合 | 北京 / 中华人民共和国首都 |
| 真包含（属种） | 一个概念包含另一个 | 学生 / 大学生 |
| 交叉 | 部分重合 | 教师 / 党员 |
| 全异 | 完全不重合 | 矛盾关系（生/死）、反对关系（黑/白） |

### 二、直言命题与对当关系

四种命题：**全称肯定 A**（所有 S 是 P）、**全称否定 E**（所有 S 不是 P）、**特称肯定 I**（有些 S 是 P）、**特称否定 O**（有些 S 不是 P）。

| 关系 | 命题对 | 真假规律 |
|---|---|---|
| **矛盾** | A–O、E–I | 必一真一假 |
| **反对** | A–E | 不能同真，可以同假 |
| **下反对** | I–O | 不能同假，可以同真 |
| **从属** | A→I、E→O | 全称真则特称真 |

**负命题转换（高频）：**
- 并非"所有 S 是 P" = "有些 S 不是 P"
- 并非"所有 S 不是 P" = "有些 S 是 P"
- 并非"有些 S 是 P" = "所有 S 不是 P"

### 三、三段论

由两个前提推出结论。**规则：中项至少周延一次；前提中不周延的项，结论中也不得周延；两个否定前提推不出结论。**

> 例：所有教师都是教育工作者（A），有些教师是党员（I），所以有些教育工作者是党员（I）。

### 四、复言命题

| 类型 | 形式 | 真假规则 |
|---|---|---|
| 联言 | p 且 q | **全真才真**，一假即假 |
| 相容选言 | p 或 q | 至少一真即真，**全假才假** |
| 不相容选言 | 要么 p，要么 q | 一真一假才真 |
| **充分条件假言** | 如果 p，那么 q（p→q） | **只有 p 真 q 假时为假** |
| **必要条件假言** | 只有 p，才 q（q→p） | 只有 p 假 q 真时为假 |

**负命题等价转换（必背）：**
- 并非（p 且 q）= 非 p **或** 非 q
- 并非（p 或 q）= 非 p **且** 非 q
- 并非（如果 p 那么 q）= **p 且非 q**
- 并非（只有 p 才 q）= 非 p 且 q

**推理规则：**
- 充分条件：肯前必肯后，否后必否前；否前肯后不必然
- 必要条件：否前必否后，肯后必肯前

### 五、图形推理

看四类：**位置**（平移、旋转、翻转、相对位置）、**样式**（叠加、去同存异、遍历）、**数量**（点、线、面、角、素）、**属性**（对称性、曲直性、封闭性）。

### 六、数字推理

常见规律：等差数列、等比数列、和数列（前两项之和）、积数列、平方/立方数列、分数数列、组合数列（奇偶项分别成规律）。

### 七、一般推理

排除法、假设法（假设某条件成立，推出矛盾则否定）、列表法、图表法。

## 第三节 阅读理解（材料分析 14 分）

> 考的是社科类议论文，两道小题，共 14 分。

### 一、细节理解题

**（1）理解文中重要概念的含义**
- 答题格式：**"××"在文中指的是……**（用原文语句或概括性语言）
- 方法：找概念出现的上下文，抓"即""也就是说""所谓"等提示词

**（2）理解文中重要句子的含义**
- 方法：结合句子在文中的位置（开头总起、中间过渡、结尾总结）推断；抓修辞还原本义；抓关键词拆解

### 二、主旨观点题

- 找**中心句**：多在首段、尾段、段落首句
- 抓**关联词**：转折（但是、然而）、因果（因此、所以）、递进（更、甚至）
- 概括要求：**全面、准确、简洁**，不能只抓局部

### 三、答题模板

```
第一问（理解含义类）：
① 该句/该词表面意思是……
② 结合上下文，作者实际想表达的是……
③ 这句话在文中的作用是……

第二问（概括观点类）：
① 文章首先指出……
② 接着分析了……
③ 最后得出结论……
```

> **踩分提醒：** 阅读理解必须**引用原文关键词**，纯自己发挥最多给一半分。

## 第四节 写作能力（50 分，决定生死）

### 一、审题

- **审文体**：明确要求"议论文"就写议论文，不要写成记叙文或散文
- **审题型**：命题作文、话题作文、材料作文（教资以**材料作文**为主）
- **审要求**：字数（不少于 800 字）、不得抄袭、自拟标题

### 二、立意（最关键，跑题直接 20 分以下）

**方法一：抓关键句法** —— 材料中反复出现、带有评价色彩的句子就是立意点
**方法二：由果溯因法** —— 材料给了结果，追问"为什么"，原因即立意

**立意要求：** 正确（符合教育价值观）、集中（一个中心论点）、深刻（能上升到教育本质）、新颖（避免人云亦云）

> 教资作文的隐藏加分项：**立意往"教育"上靠**。哪怕材料讲的是社会现象，也要落到教师、学生、教育上。

### 三、布局（五段式万能结构）

```
标题（1 行，观点式，不用问句）
第一段：开头（100–150 字）——引材料 + 亮观点
第二段：分论点一 + 论据 + 分析（200 字）
第三段：分论点二 + 论据 + 分析（200 字）
第四段：分论点三 + 论据 + 分析（200 字）
第五段：结尾（100 字）——回扣观点 + 升华
```

**分论点展开方式：**
- **并列式**：是什么 / 为什么 / 怎么办，三个角度平行
- **递进式**：个人 → 社会 → 国家；或 认知 → 实践 → 价值
- **对照式**：正反对比

### 四、开头与结尾模板

**开头（三种）：**
1. **引材式**：材料中……的现象引人深思。在我看来，……
2. **名言式**：苏霍姆林斯基曾说："……"这句话告诉我们，……
3. **对比式**：有人说……，也有人说……。我认为，……

**结尾（三种）：**
1. **号召式**：让我们……，让每一个孩子都能……
2. **升华式**：教育是一棵树摇动另一棵树……作为未来的人民教师，我愿……
3. **回扣式**：综上，……不仅是……，更是……

### 六、写作硬性提醒

1. **必须写满 800 字**，差 50 字扣 1 分，写不到 600 字直接不及格档。
2. **标题必须有**，无标题扣 2 分。
3. **不能出现真实姓名、学校**，用"李老师""某小学"代替。
4. **字迹工整**，卷面分实打实存在（3–5 分）。
5. **时间分配**：阅读 + 单选 40 分钟，材料分析 30 分钟，作文 50 分钟。
