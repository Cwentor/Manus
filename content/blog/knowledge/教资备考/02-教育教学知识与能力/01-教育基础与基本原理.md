## 一、教育的概念与属性

### 1. 教育的概念

- **广义**：一切有目的地增进人的知识技能、影响人的思想品德的活动。包括学校教育、家庭教育、社会教育。
- **狭义（学校教育）**：教育者根据一定的社会要求，有目的、有计划、有组织地对受教育者施加影响，促使其朝着期望方向发展的活动。
- **词源**："教育"一词最早见于《**孟子·尽心上**》："得天下英才而教育之"。最早把"教""育"分开解释的是《**说文解字**》：许慎，"教，上所施，下所效也""育，养子使作善也"。

### 2. 教育的基本要素

**教育者、受教育者、教育影响（教育内容 + 教育手段）**——其中**教育者是主导，受教育者是主体**。

### 3. 教育的本质属性（重点，考过 18 次）

**教育是一种有目的地培养人的社会活动。** 这是教育区别于其他一切社会活动的根本特征，即教育的**质的规定性**。

三层理解：
1. 教育是人类所特有的有意识的社会活动（动物界没有教育）
2. 教育是人类有意识地传递社会经验的活动
3. 教育是以培养人为直接目标的社会实践活动

> **经典辨析：** "影响人身心发展的活动都是教育"——错，无目的的、偶然的影响不是教育；"动物界也存在教育"——错。

### 4. 教育的社会属性

| 属性 | 含义 | 常见考法 |
|---|---|---|
| **永恒性** | 与人类社会共始终 | "教育随人类社会的产生而产生" |
| **历史性** | 不同历史时期教育性质不同 | 新中国教育不同于古代教育 |
| **相对独立性** | 教育有自身规律，与社会发展不完全同步 | 教育可超前/滞后于生产力 |
| **生产性** | 教育是劳动力再生产的手段 | 教育为社会生产服务 |
| **民族性** | 教育在民族和国家中进行 | 考频低 |

**教育的相对独立性（简答高频）：**
1. 教育具有质的规定性（是有目的地培养人的活动）
2. 教育具有历史继承性（继承教育内容、方式、理论与经验）
3. 教育具有与生产力和政治经济制度发展的**不平衡性**（可超前或滞后）
4. 教育要受其他社会意识形态的影响

### 5. 教育的功能

- **按对象**：个体功能（本体功能）／社会功能（派生功能）
- **按方向**：正向功能／负向功能
- **按呈现**：显性功能／隐性功能

## 二、教育的产生与发展

### 1. 教育起源说

| 学说 | 代表人物 | 观点 | 口诀 |
|---|---|---|---|
| **神话起源说** | — | 教育由神创造 | 最古老 |
| **生物起源说** | 利托尔诺（法）、沛西·能（英） | 教育源于动物界的生存本能 | **本能生利息** |
| **心理起源说** | 孟禄（美） | 教育源于儿童对成人的无意识模仿 | **心理仿孟禄** |
| **劳动起源说** | 米丁斯基、凯洛夫（苏） | 教育源于人类的生产劳动 | **米凯爱劳动** |
| 交往起源说 | 叶澜（中） | 教育源于人类的交往活动 | — |

### 2. 教育的历史发展

| 阶段 | 特征 |
|---|---|
| **原始社会** | 教育与社会生产劳动、生活**结合**；无阶级性、公平性；内容简单、方法单一（口耳相传） |
| **古代社会** | ① 教育**与生产劳动相脱离**，具有非生产性 ② 鲜明的**阶级性和等级性** ③ 道统性、专制性、刻板性、象征性 ④ 教育内容形式单一 ⑤ 教学方法死板 ⑥ 个别教学 |
| **近现代社会** | ① 国家加强干预，**公立教育崛起** ② **初等义务教育**普遍实施 ③ 教育的**世俗化** ④ 重视**教育立法**，依法执教 |

**古代教育口诀：劳教脱离有阶级，个别教学象征意，只是方法死板还单一。**
**近代教育口诀：公义世法**（公立教育、义务教育、世俗化、法制化）。

**20 世纪以后教育的特点（简答）：** 教育的**全民化、民主化、多元化、技术现代化、终身化**。

### 3. 古代学校教育的形态

- **中国**：夏商已有学校（庠、序、校）；西周"**学在官府**"；汉代**太学**；隋唐科举；宋元书院；明清八股。
- **西方**：古埃及（宫廷学校、文士学校）；古印度（婆罗门教育）；古希腊——**雅典**（培养德智体美和谐发展的人，"**文雅教育**"）与**斯巴达**（培养军人，军事体育训练）。

## 四、教育与社会发展

### 1. 教育与生产力

- 生产力**决定**教育的**规模与速度**、**结构**、**内容与方法**
- 教育**反作用**于生产力：**劳动力再生产**（最主要）、科学知识再生产、技术创新

### 2. 教育与社会政治经济制度

- 政治经济制度**决定**教育的**领导权、受教育权、教育目的的性质、教育内容的取舍**
- 教育**反作用**：培养所需人才、传播思想形成舆论、促进民主政治

### 3. 教育与文化

- 文化影响教育目的、内容、传统；教育具有**传递保存、传播交流、选择提升、创造更新**文化的功能

### 4. 教育与人口

- 人口数量、结构、质量影响教育；教育可控制人口增长、提高人口质量、优化人口结构

## 五、教育与人的发展

### 1. 个体身心发展的一般规律（简答高频）

| 规律 | 含义 | 教育启示 |
|---|---|---|
| **顺序性** | 由低到高、由简到繁，不可逆 | **循序渐进**，不陵节而施 |
| **阶段性** | 不同年龄阶段有不同特征和任务 | 分阶段教学，不"一刀切" |
| **不平衡性** | 同一方面不同速，不同方面不同步 | 抓住**关键期**（劳伦兹"印刻"） |
| **互补性** | 生理与生理、生理与心理可互相补偿 | **长善救失**，扬长避短 |
| **个别差异性** | 个体之间、群体之间存在差异 | **因材施教** |

### 2. 影响个体身心发展的因素

| 因素 | 作用 |
|---|---|
| **遗传** | 提供**生理前提**和可能性；造成个别差异 |
| **环境** | 提供**现实条件**；把可能变为现实 |
| **学校教育** | 起**主导作用**（有目的、有计划、有组织，专门人员） |
| **个体主观能动性** | **决定性因素**，内在动力 |

**学校教育为什么能起主导作用：** ① 有目的、有计划、有组织 ② 由专门人员（教师）承担 ③ 能有效控制和协调各种影响因素 ④ 给人全面系统的影响

**教育发挥主导作用的条件：** 尊重学生身心发展规律；调动学生主观能动性；协调家庭与社会影响；教师自身素质。

### 3. 关于人的发展理论

- **内发论**（遗传决定论）：孟子（性善）、弗洛伊德、威尔逊、格塞尔（成熟势力说）、霍尔（"一两的遗传胜过一吨的教育"）
- **外铄论**（环境决定论）：荀子（性恶）、洛克（白板说）、华生（"给我一打健康的婴儿……"）
- **辐合论**：施太伦

## 六、教育目的

### 1. 概念与层次

- **教育目的**（国家层面，最高）→ **培养目标**（学校层面）→ **课程目标**（学科层面）→ **教学目标**（课堂层面）

### 2. 教育目的的价值取向

| 取向 | 主张 | 代表 |
|---|---|---|
| **个人本位论** | 教育目的依据个人需要 | 卢梭、裴斯泰洛齐、马斯洛、罗杰斯 |
| **社会本位论** | 教育目的依据社会需要 | 柏拉图、涂尔干、凯兴斯泰纳、孔德 |
| 教育无目的论 | 教育即生长，教育过程本身就是目的 | 杜威 |

### 3. 我国的教育目的

**"以培养学生的创新精神和实践能力为重点，造就有理想、有道德、有文化、有纪律的德智体美劳全面发展的社会主义建设者和接班人。"**

**确立依据：** 马克思主义关于**人的全面发展学说**（我国教育目的的理论基础）、社会生产力和生产关系的要求、受教育者身心发展规律。

### 4. 全面发展教育的构成（简答必背）

| 各育 | 地位与作用 |
|---|---|
| **德育** | **灵魂与统帅**，起方向性保证作用 |
| **智育** | **前提与基础**，提供知识基础和能力基础 |
| **体育** | **物质前提**，是人的一切活动的基础 |
| **美育** | **动力作用**，协调各育发展 |
| **劳动技术教育** | 综合德智体美的**实践基础** |

> 五者相互独立、相互依存、相互促进，不可偏废。**全面发展 ≠ 平均发展。**

## 七、教育制度

### 1. 概念与影响因素

- **狭义教育制度**指**学校教育制度（学制）**：一个国家各级各类学校的总体系，规定学校的性质、任务、入学条件、修业年限及彼此关系。
- 影响因素：生产力水平、社会政治经济制度、人的身心发展规律、人口发展状况、本国学制传统与外国学制影响。

### 2. 现代学制的类型

| 类型 | 特点 | 代表国家 |
|---|---|---|
| **双轨制** | 一轨为资产阶级子女（学术性），一轨为劳动人民子女（职业性），两轨不通 | 西欧（英、法、德） |
| **单轨制** | 自下而上贯通，人人可入同一学校系统 | **美国** |
| **分支型学制** | 前段统一，后段分叉（苏联型） | 中国、苏联 |

### 3. 我国学制的沿革

| 学制 | 年份 | 地位 |
|---|---|---|
| **壬寅学制** | 1902 | **首次颁布**但未实行 |
| **癸卯学制** | 1904 | **首次实行**，标志我国近代学制建立；"中学为体，西学为用" |
| 壬子癸丑学制 | 1912–1913 | 首次规定**男女同校** |
| **壬戌学制** | 1922 | "**六三三学制**"，以美国为蓝本，影响最大、使用最久 |
| 现行学制 | 1951 至今 | 九年义务教育 |

### 4. 义务教育

- 特征：**强制性、免费性、普及性**（统一性）
- 我国 1986 年颁布《义务教育法》，年限**九年**

## 八、小学教育的特点与教育研究

### 1. 小学教育的特点

**全民性、义务性、全面性**（面向全体、面向全面发展）；此外具有基础性、启蒙性。

### 2. 教育科学研究

**基本过程：** 确定研究课题 → 查阅文献 → 提出研究假设 → 制定研究计划 → 收集资料 → 分析资料、得出结论 → 撰写研究报告

**常用方法：**

| 方法 | 特点 |
|---|---|
| **观察法** | 有目的、有计划地感知对象（最基础、最常用） |
| **调查法** | 问卷、访谈、测验；了解现状 |
| **实验法** | 主动控制条件，探究因果关系（**唯一能确定因果**的方法） |
| **个案法** | 对单一对象深入研究 |
| **行动研究法** | 教师在实践中研究，**教学与研究合一**、循环性、改进实践 |
| **教育叙事研究** | 讲述教育故事，反思经验 |

**课题选择的原则（口诀：可教轮椅践行）：** 教育性、实践性、可行性、适宜性、伦理性

**文献检索方法（口诀：顺逆查文综）：** 顺查法、逆查法、引文查找法、综合查找法

**文献检索要求（口诀：内外全面撰）：** 内部评论与外部评论；全面、准确检索；以分析概括为基础撰写综述报告

**行动研究的特征（口诀：一起遵循内幕）：** 目的是改进实践；内容是教育教学中的问题；教学与研究合一；研究的循环性
