## 第一节 心理学基础

### 一、注意

| 分类 | 特点 | 例子 |
|---|---|---|
| **无意注意**（不随意注意） | 无预定目的、不需意志努力 | 上课时窗外传来巨响，学生转头 |
| **有意注意**（随意注意） | 有预定目的、需意志努力 | 学生强迫自己听枯燥的课 |
| **有意后注意**（随意后注意） | 有目的、不需意志努力 | 熟练阅读、边聊天边织毛衣 |

**注意的品质：** 注意的范围（广度）、注意的稳定性（持续性，与之相反是**分散**）、注意的分配（一心二用）、注意的转移（主动改变）。

**注意规律在教学中的应用：** ① 运用无意注意的规律组织教学（教室布置、语言生动）② 运用有意注意的规律（明确目的、严格要求）③ 两种注意交替使用 ④ 培养学生良好的注意品质。

### 二、感觉与知觉

- **感觉**：个别属性的反映。**感受性与感觉阈限成反比**。
- **感觉的相互作用**：同一感觉的**适应**（暗适应、明适应）、**对比**（同时对比、继时对比）、**后像**；不同感觉的**联觉**（"甜美的声音"）。
- **知觉的特性**：**整体性、选择性、理解性、恒常性**。
- **观察力**：知觉的高级形式，有目的、有计划、比较持久。

### 三、记忆

**分类：**

| 标准 | 类型 |
|---|---|
| 保持时间 | **瞬时记忆**（0.25–2 秒）、**短时记忆**（≤1 分钟，容量 7±2 个组块）、**长时记忆**（>1 分钟） |
| 内容 | 形象记忆、逻辑记忆、情绪记忆、动作记忆 |
| 意识参与 | 外显记忆、内隐记忆 |

**记忆过程：** **识记 → 保持 → 再认或回忆**

**遗忘规律（艾宾浩斯遗忘曲线）：先快后慢，呈负加速。**

**影响遗忘进程的因素（简答）：**
1. 学习材料的性质
2. 识记材料的数量和学习程度的大小（过度学习 **150%** 效果最佳）
3. 记忆任务的长久性与重要性
4. 识记的方法
5. 时间因素
6. 材料的系列位置效应（**首因效应、近因效应**）
7. 情绪和动机（耶克斯—多德森定律）

**遗忘理论：** 衰退说、干扰说（**前摄抑制、倒摄抑制**）、压抑说（动机性遗忘）、提取失败说（舌尖现象）。

**促进记忆的方法：** 明确目的、及时复习、分散复习与集中复习结合、反复阅读与试图回忆结合、多种感官参与、适当过度学习、合理组织材料（**组块化**）。

### 四、思维

| 分类标准 | 类型 |
|---|---|
| 发展水平 | 直观动作思维 → 具体形象思维 → **抽象逻辑思维** |
| 逻辑性 | 直觉思维、分析思维 |
| 指向性 | **聚合思维**（求同）、**发散思维**（求异，创造性核心） |
| 创新程度 | 常规思维、创造性思维 |

**创造性思维的特征：** 流畅性、变通性（灵活性）、独创性。

**问题解决：**
- 影响问题解决的因素：问题的特征、**定势与功能固着**、已有的知识经验、原型启发、情绪与动机、个性特征
- 策略：算法式（保证成功但费时）、**启发式**（手段—目的分析、逆向搜索、爬山法）

### 五、想象

- 分类：无意想象（梦、幻觉）／有意想象（**再造想象、创造想象、幻想**——理想与空想）
- 培养学生想象力的方法：丰富表象、发展语言、结合学科教学、鼓励大胆想象与质疑

## 第二节 小学生心理发展

### 一、心理发展的一般特点

**顺序性、阶段性、连续性、不平衡性、差异性、关键期**（印刻实验，劳伦兹）。

### 二、认知发展理论（简答高频）

**皮亚杰的认知发展阶段论**

| 阶段 | 年龄 | 特征 |
|---|---|---|
| **感知运动阶段** | 0–2 岁 | 感觉与动作分化；获得**客体永久性** |
| **前运算阶段** | 2–7 岁 | 用表象符号代替外界事物；**自我中心**（三山实验）；思维**不可逆**；**泛灵论**；未获得守恒 |
| **具体运算阶段** | 7–11 岁 | **去自我中心**；获得**守恒**概念；思维可逆；能进行具体逻辑推理 |
| **形式运算阶段** | 11–16 岁 | 抽象逻辑思维；**假设—演绎推理**；思维接近成人 |

> 关键概念：**图式、同化、顺应、平衡**（认知发展的四个关键词）。

**维果茨基的"最近发展区"**

> 最近发展区是儿童在有指导的情况下，借助成人帮助所能达到的解决问题的水平，与独自解决问题所达到的水平之间的**差异**。教学不应只适应发展的现有水平，而应**走在发展的前面**，"教学创造着最近发展区"。

**皮亚杰的道德发展阶段论**

| 阶段 | 年龄 | 特征 |
|---|---|---|
| **自我中心阶段**（前道德阶段） | 2–5 岁 | 无规则意识，行为多与生理本能满足有关 |
| **权威阶段**（他律道德阶段） | 5–8 岁 | 服从成人，认为规则不可改变；**绝对化**评价（好/坏） |
| **可逆性阶段**（自律道德阶段） | 8–10 岁 | 规则可协商改变；**相互尊重** |
| **公正阶段** | 10–12 岁 | 考虑具体情况，追求**公正平等** |

**科尔伯格的道德发展三水平六阶段：** 前习俗水平（惩罚服从、相对功利）→ 习俗水平（好孩子、维护权威秩序）→ 后习俗水平（社会契约、普遍伦理）。

### 三、小学生认知发展的特点

- **注意**：无意注意占优势，有意注意逐步发展；注意的稳定性差，范围小
- **记忆**：从**无意识记**向有意识记发展；从**机械记忆**向意义记忆发展；从**具体形象记忆**向抽象记忆发展
- **思维**：从**具体形象思维**为主，逐步向**抽象逻辑思维**过渡（小学中高年级是关键转折）
- **想象**：从无意想象向有意想象发展，从再造想象向创造想象发展

### 四、情绪、情感与意志

**情绪状态分类：** **心境**（弥散、持久）、**激情**（强烈、短暂、爆发）、**应激**（突发情况下的高度紧张）。

**情感分类：** 道德感、理智感、美感。

**意志品质：** 自觉性（反之：易受暗示、独断）、果断性（反之：优柔寡断、草率）、坚韧性（反之：动摇、执拗）、自制性（反之：任性、怯懦）。

**意志行动过程：** 采取决定阶段（动机斗争、确定目的、选择方法）→ 执行决定阶段。

## 第三节 学习理论

### 一、行为主义学习理论

| 人物 | 实验 | 观点 |
|---|---|---|
| **巴甫洛夫** | 狗唾液分泌 | **经典性条件作用**；获得与消退、**泛化与分化** |
| **桑代克** | 饿猫逃出迷笼 | **试误说**；**准备律、练习律、效果律**（三律） |
| **斯金纳** | 斯金纳箱 | **操作性条件作用**；**强化**（正强化/负强化）、**惩罚**、**消退**；程序教学 |
| **班杜拉** | 波波玩偶 | **社会学习理论**；**观察学习**（注意—保持—再现—动机）；**自我效能感** |

> **易混：** 正强化=给愉快刺激增行为；负强化=撤厌恶刺激增行为；惩罚=给厌恶刺激减行为；消退=不强化使行为消失。

### 二、认知学习理论

- **苛勒**：完形—顿悟说（黑猩猩取香蕉）
- **托尔曼**：符号学习论，**潜伏学习**
- **布鲁纳**：**认知—结构学习论**，倡导**发现学习**；学科基本结构
- **奥苏贝尔**：**有意义接受学习**；**先行组织者**；**成就动机**三内驱力（认知内驱力、自我提高内驱力、附属内驱力）

**有意义学习的实质与条件（简答）：**
- 实质：将新知识与已有知识建立起**非人为的（内在的）**和**实质性的（非字面的）**联系
- 条件：① 学习材料本身具有**逻辑意义** ② 学习者具有**有意义学习的心向** ③ 学习者认知结构中具有**同化新知识的适当观念**

### 三、建构主义学习理论

- 知识不是被动接受，而是学习者主动建构的
- **情境、协作、会话、意义建构**（四大要素）
- 学生不是空着脑袋进教室的；教师是引导者、帮助者、合作者
- 代表：皮亚杰、维果茨基（**支架式教学**）、斯皮罗（随机通达教学）

### 四、人本主义学习理论

- **马斯洛**：需要层次理论（生理、安全、归属与爱、尊重、自我实现）
- **罗杰斯**：**非指导性教学**、学生中心、**有意义的自由学习**；教师是"促进者"

## 第四节 学习动机、迁移与策略

### 一、学习动机

**分类：**
- 按动力来源：**内部动机**／外部动机
- 按社会意义：高尚动机／低级动机
- 按作用时间：近景直接性动机／远景间接性动机
- 奥苏贝尔：**认知内驱力**（最稳定、最重要）、自我提高内驱力、附属内驱力

**理论：**

| 理论 | 人物 | 核心观点 |
|---|---|---|
| **强化理论** | 斯金纳 | 动机由外部强化引起 |
| **需要层次理论** | 马斯洛 | 缺失性需要满足后才追求成长性需要 |
| **成就动机理论** | 阿特金森 | 力求成功者选**中等难度**（50%）任务；避免失败者选极易或极难任务 |
| **成败归因理论** | **韦纳** | 三维度：**内部/外部、稳定/不稳定、可控/不可控**；能力（内部稳定不可控）、努力（内部不稳定可控）、任务难度（外部稳定不可控）、运气（外部不稳定不可控） |
| **自我效能感理论** | **班杜拉** | 影响自我效能感的因素：成败经验（最主要）、替代性经验、言语说服、情绪唤醒 |
| **自我价值理论** | 科温顿 | 学生通过不努力来保护自我价值 |

**如何激发与培养学生的学习动机（简答，口诀：控制奖惩）：**
1. **创设问题情境，实施启发式教学**
2. **充分利用反馈信息，妥善进行奖惩**
3. **根据作业难度，恰当控制动机水平**（耶克斯—多德森定律：中等动机水平效率最高；任务越难，最佳动机水平越低）
4. **正确指导结果归因，促使学生继续努力**（引导归因于"努力"）
5. 表达明确期望、提供成功机会、培养自我效能感

### 二、学习迁移

**分类：**

| 标准 | 类型 |
|---|---|
| 性质 | **正迁移**（促进）／负迁移（干扰） |
| 方向 | 顺向迁移（前→后）／逆向迁移（后→前） |
| 水平 | 水平迁移（同一难度）／垂直迁移（不同难度） |
| 内容 | 一般迁移／**具体迁移** |
| 心理机制 | 同化性迁移、顺应性迁移、重组性迁移 |

**理论：** 形式训练说（最早，沃尔夫）→ 共同要素说（桑代克）→ 概括化理论（贾德，水下击靶）→ 关系转换说（苛勒）→ 认知结构迁移理论（奥苏贝尔）

**影响迁移的因素（简答）：**
1. 学习任务的**相似性**
2. 原有的**认知结构**
3. 学习的**心向与定势**
4. 学习的**指导**（教师的指导、学习策略）

**如何促进学习迁移（简答）：**
1. **学生角度**：关注学生原有的知识经验和认知结构
2. **教学角度**：精心设置教学环节（比较、概括、变式练习）
3. **策略角度**：教授学习策略，提高迁移意识

### 三、学习策略

| 类型 | 具体策略 |
|---|---|
| **认知策略** | **复述策略**（重复、划线）、**精加工策略**（记忆术、做笔记、提问、生成性学习）、**组织策略**（列提纲、画图表、归类） |
| **元认知策略** | 计划策略、监控策略、调节策略 |
| **资源管理策略** | 时间管理、环境管理、努力管理、**学业求助** |

## 第五节 知识与技能的学习

### 一、知识的学习

**知识分类（安德森）：** 陈述性知识（是什么）／程序性知识（怎么做）。

**知识直观：** 实物直观、模象直观、言语直观。

**促进知识保持的方法：** 深度加工、有效运用记忆术、进行组块化编码、适当过度学习、合理进行复习。

**迁移分类（奥苏贝尔）：** 下位学习（类属学习）、上位学习（总括学习）、并列组合学习。

### 二、技能的形成

| 类型 | 形成阶段 |
|---|---|
| **操作技能** | 操作**定向** → 操作**模仿** → 操作**整合** → 操作**熟练** |
| **心智技能** | **原型定向** → **原型操作** → **原型内化** |

**操作技能的培训要求：** 准确的示范与讲解、必要而适当的练习（**练习曲线**有高原现象）、充分而有效的反馈、建立稳定清晰的动觉。

## 第六节 德育

### 一、德育的概念与内容

- **广义**：社会德育、社区德育、学校德育、家庭德育
- **学校德育**：教育者按照一定社会或阶级的要求，有目的、有计划、系统地对受教育者施加思想、政治、道德影响，使其形成一定社会与阶级所需要的思想品德的活动。
- **内容**：**政治教育、思想教育、道德教育、法制教育、心理健康教育**（我国中小学德育内容：爱国主义、集体主义、社会主义、理想、道德、纪律、法制、心理健康）

### 二、德育过程的基本规律（简答必背）

1. 德育过程是**促使学生的知、情、意、行互动发展**的过程（**知是基础、行是关键**；德育具有多开端性）
2. 德育过程是**组织学生的活动和交往，统一多方面教育影响**的过程
3. 德育过程是**促进学生思想品德内部矛盾积极转化**的过程
4. 德育过程是一个**长期性、反复性、逐步提高**的过程

### 三、德育原则（8 条，材料分析必考）

| 原则 | 含义 | 贯彻要求 |
|---|---|---|
| **导向性原则** | 坚持正确政治方向 | 明确方向、符合方针、结合时代 |
| **疏导原则**（循循善诱） | 讲明道理、疏导思想 | 以理服人、因势利导、以表扬激励为主 |
| **尊重学生与严格要求相结合** | 严慈相济 | 爱护尊重信任学生；提出合理、具体、适度的要求；要求认真执行 |
| **知行统一原则** | 言行一致 | 加强理论教育；组织实践活动；评价和要求坚持知行统一；教师以身作则 |
| **正面教育与纪律约束相结合** | 引导 + 约束 | 正面引导说服；辅以纪律约束；健全规章制度 |
| **依靠积极因素，克服消极因素**（长善救失） | 用优点克服缺点 | 一分为二看待学生；创造机会发扬积极因素 |
| **教育影响的一致性与连贯性** | 家校社协同 | 统一认识、统一要求；形成教育合力；保持连贯 |
| **因材施教原则** | 区别对待 | 了解学生个性特点；有的放矢 |

### 四、德育方法（6 种，口诀：说好月利息）

1. **说服教育法**（讲解、谈话、讨论、参观）——**最基本的方法**
2. **榜样示范法**（伟人、教师、同伴）
3. **实际锻炼法**（练习、制度、委托任务）
4. **品德修养指导法**（自我反省、座右铭、自我评价）
5. **陶冶教育法**（人格感化、环境陶冶、艺术陶冶）
6. **品德评价法**（表扬奖励、批评处分、操行评定）

**德育途径：** 思想品德课与其他学科教学（**最基本、最经常**）、课外校外活动、劳动与社会实践、共青团少先队活动、班主任工作、校园文化。

### 五、小学生品德发展

**品德的心理结构：** **道德认识**（核心）、道德情感、道德意志、道德行为（**衡量品德的根本标志**）。

**学生形成良好态度和品德的方法（简答，口诀：说好月利息）：**
1. **有效的说服**
2. **树立良好的榜样**
3. **利用群体约定**
4. **给予恰当的奖励与惩罚**
5. **价值辨析**

**矫正不良品德的方法：** 改善人际关系、消除疑惧心理、保护自尊心、提高辨别是非能力、锻炼与诱因作斗争的意志力。

## 第七节 美育、心理健康与安全教育

### 一、美育

**学校美育的基本任务（简答，口诀：妹纸美观审美创美，内外都美）：**
1. 向学生传授基本的**美学知识**
2. 培养学生正确的**审美观点**
3. 培养学生的**审美能力**
4. 培养学生**创造美**的能力
5. 培养学生**内在美与外在美的统一**

> 美育在全面发展教育中起**动力作用**。

### 二、心理健康教育

**小学生常见心理障碍：** 学习困难（学习障碍）、**多动症**、焦虑症、抑郁症、恐怖症、强迫症、厌学症。

**心理健康辅导方法：** 行为改变法（强化、代币、系统脱敏、厌恶疗法）、认知疗法（理性情绪疗法—**艾里斯 ABC 理论**）、来访者中心疗法（罗杰斯）、心理暗示法、松弛训练。

**心理健康教育的途径：** 开设心理健康课程、心理辅导与咨询、学科渗透、建立心理档案、家校配合。

### 三、小学生安全教育

**常见安全问题：** 交通事故、溺水、火灾、食物中毒、校园欺凌、拐骗、网络沉迷。

**预防措施：** 开展安全教育课程与演练、建立健全安全管理制度、加强校园周边环境治理、家校协同、关注学生心理危机。

**常见急救常识：** 烫伤先冷水冲洗；溺水先清理呼吸道再心肺复苏；触电先断电；鼻出血头稍前倾捏鼻翼；骨折不随意搬动。
