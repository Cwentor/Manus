## 第一节 教学过程

### 一、教学的概念与意义

- **教学**是教育者根据一定的社会要求和学生身心发展的特点，**有目的、有计划、有组织**地引导学生掌握系统文化科学知识和技能，发展智力和体力，培养思想品德的过程。
- 教学是学校实现教育目的的**基本途径**，是学校工作的**中心环节**。

### 二、教学过程的本质

**教学过程的本质是一种特殊的认识过程**，其特殊性表现为：
1. **间接性**：以掌握间接经验为主
2. **引导性**：在教师引导下进行
3. **简捷性**：走捷径，高效掌握人类文明成果
4. **教育性**：认识过程同时是受教育过程

### 三、教学过程的基本规律（简答必背，4 条）

1. **间接经验与直接经验相统一**（以间接经验为主，以直接经验为基础）
2. **掌握知识与发展能力相统一**（掌握知识是发展能力的基础，能力发展是掌握知识的重要条件）
3. **教师的主导作用与学生的主体作用相统一**
4. **传授知识与思想品德教育相统一**（教学的教育性规律）

### 四、教学过程的基本阶段

**（1）引起学习动机** → **（2）领会知识**（**中心环节**，包括感知教材和理解教材）→ **（3）巩固知识** → **（4）运用知识** → **（5）检查知识**

## 第二节 教学原则（8 条，材料分析必考）

| 原则 | 依据/含义 | 贯彻要求 |
|---|---|---|
| **直观性原则** | 让学生通过感官获得感性认识 | 正确选择直观教具（实物、模象、语言）；直观与讲解结合；防止直观不当 |
| **启发性原则** | 调动学生主动性，引导独立思考 | **调动学生学习的主动性**（首要问题）；启发独立思考、发展逻辑思维；鼓励动手实践；发扬教学民主 |
| **循序渐进原则**（系统性） | 按学科逻辑系统和学生认识规律教学 | 按教材系统性教学；抓主要矛盾、解决重点难点；由浅入深 |
| **巩固性原则** | 牢固掌握知识技能 | 理解基础上巩固；重视复习；组织运用 |
| **因材施教原则** | 从学生实际出发，区别对待 | 了解学生；面向全体与个别指导结合；善于发现特长 |
| **理论联系实际原则** | 学以致用 | 以理论为主导；重视实践环节；补充乡土教材 |
| **科学性与思想性相统一** | 传授科学知识 + 思想品德教育 | 保证科学性；挖掘思想性；教师以身作则 |
| **量力性原则**（可接受性） | 教学难度适合学生发展水平 | 了解学生水平；难度适当；考虑个体差异 |

> **口诀：直启循巩因理思量**（直观、启发、循序、巩固、因材、理论联系实际、科学思想、量力）

**启发性教学原则的实施要求（简答）：**
1. 调动学生学习的**主动性**（启发首要问题）
2. 启发学生**独立思考**，发展逻辑思维能力
3. 鼓励学生**动手实践**，培养解决问题能力
4. 发扬**教学民主**（允许质疑、宽容不同观点）

## 第三节 教学方法

### 一、教学方法选用的依据（简答，口诀：一课程二师生三教学）

1. **课程性质和教材特点**
2. **教师的业务水平、实际经验及个性特点**
3. **学生的年龄、身心特点**
4. **教学目标和任务要求**
5. 教学重难点、教学环境、设备条件

### 二、常用的教学方法

| 类别 | 方法 | 要点 |
|---|---|---|
| **以语言传递为主** | **讲授法** | 讲述、讲解、讲读、讲演；**最常用**，能在短时间内传授大量系统知识 |
| | **谈话法** | 问答式，分复习谈话和启发谈话 |
| | **讨论法** | 学生围绕问题讨论，需高年级 |
| | **读书指导法** | 指导学生阅读教材和课外书 |
| **以直观感知为主** | **演示法** | 展示实物、教具、实验 |
| | **参观法** | 到现场观察（准备、实施、总结） |
| **以实际训练为主** | **练习法** | 巩固知识、形成技能 |
| | **实验法** | 学生操作实验 |
| | **实习作业法** | 学以致用 |
| | 实践活动法 | 社会实践 |
| **以情感陶冶为主** | 欣赏教学法、情境教学法 | 创设情境、体验情感 |

### 三、教学方法的改革趋势

- 由**重教**转向**重学**
- 由**单一**转向**多样**
- 由**封闭**转向**开放**
- 由**被动接受**转向**主动探究**

## 第四节 教学组织形式

| 形式 | 特点 |
|---|---|
| **个别教学制** | 最早的形式，一对一，效率低 |
| **班级授课制** | **夸美纽斯**系统论述；我国始于**1862 年京师同文馆**；**基本形式**；优点是效率高、利于集体教育；缺点是不利于因材施教 |
| **分组教学** | 能力分组/作业分组；外部分组/内部分组 |
| **设计教学法** | 克伯屈，学生自定目的、自行设计 |
| **道尔顿制** | 帕克赫斯特，废除课堂讲授，学生自学 + 教师辅导 |
| **文纳特卡制** | 华虚朋，个别学习 + 团体活动 |
| **复式教学** | 一个教师同时教两个以上年级（**特殊的班级授课制**） |
| **现场教学** | 到现场进行教学 |

**班级授课制的辅助形式：** 个别辅导、现场教学。
**教学的特殊组织形式：** 复式教学。

## 第五节 教学工作的基本环节

### 一、备课（**前提**）

**三备：** 备**教材**、备**学生**、备**教法**
**三计划：** 学期（学年）教学进度计划、单元计划、**课时计划（教案）**

**一堂好课的标准：** 目标明确、内容正确、方法得当、表达清晰、组织严密、气氛热烈、**学生主体性发挥**。

### 二、上课（**中心环节**）

一堂好课的要求：
1. 目标明确
2. 内容正确
3. 方法得当
4. 表达清晰
5. 组织严密
6. 气氛热烈
7. 充分发挥学生的主体性（**最根本**）

### 三、作业的布置与批改

要求：内容符合大纲和教材要求；分量适当、难度适度；形式多样；有明确要求和指导；及时批改与反馈。

### 四、课外辅导

面向全体、因材施教；重点辅导后进生和优等生。

### 五、学业成绩的检查与评定

**方式：** 考查（口头提问、书面作业、检查笔记）、考试（期中、期末）。
**评定要求：** 客观公正、鼓励为主、及时反馈、定性与定量结合。

## 第六节 新课程倡导的学习方式

| 方式 | 内涵 | 教师角色 |
|---|---|---|
| **自主学习** | 学生自己确定学习目标、选择方法、监控过程、评价结果（**自立性、自为性、自律性**） | 指导者 |
| **合作学习** | **有明确责任分工**的互助性学习（异质分组、共同目标、个体责任、相互依赖） | 组织者 |
| **探究学习** | 从问题出发，经历"提出问题—假设—验证—结论"的过程（**问题性、实践性、开放性、生成性**） | 引导者 |

> **合作学习的要素：** 积极的相互依赖、面对面的促进性互动、个体责任、社交技能、小组自评。

## 第七节 教学评价

### 一、教学评价的功能

导向功能、诊断功能、**激励功能**、调节功能、教学功能、管理功能。

### 二、教学评价的类型

| 分类标准 | 类型 |
|---|---|
| **按评价功能（时间）** | **诊断性评价**（教学前）、**形成性评价**（教学中，如课堂提问、单元测验）、**总结性评价**（教学后，如期末考试） |
| **按评价标准** | **相对评价**（常模参照，排名）、**绝对评价**（标准参照，达标）、**个体内差异评价**（自己与自己比） |
| **按评价方法** | 定量评价、定性评价 |
| **按评价主体** | 自我评价、他人评价 |

### 三、新课改的评价理念

1. 评价目的是**促进发展**（而非甄别选拔）
2. 评价内容**综合化**
3. 评价方式**多样化**（定性+定量、形成性+终结性）
4. 评价主体**多元化**
5. 评价标准**分层化**，关注个体差异
6. **注重过程**，形成性评价与终结性评价相结合

### 四、教学反思

**反思的内容：** 教学理念、教学目标、教学内容、教学方法、教学过程、教学效果。

**反思的方法（口诀：日记描述交流）：**
1. **反思日记**
2. **详细描述**（观摩他人、记录案例）
3. **交流讨论**（与同事研讨）
4. 行动研究

**反思的意义：** ① 有助于教师把经验升华为理论 ② 有助于提升教育教学实践的合理性 ③ 缩短专业化成长时间。

## 第八节 教学设计基础（详见 06 文件）

教学设计的基本要素：
1. **教学目标**（知识与技能、过程与方法、情感态度与价值观——**三维目标**）
2. **教学重难点**（重点是学科核心内容，难点是学生难以理解之处）
3. **教学方法**
4. **教学过程**（导入—新授—巩固—小结—作业）
5. **板书设计**
6. **教学反思**
