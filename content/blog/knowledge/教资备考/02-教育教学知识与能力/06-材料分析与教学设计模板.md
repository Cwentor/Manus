# 第一部分 材料分析题（2 题，40 分）

## 一、答题总原则

1. **先定性，再分点，最后总结**——三步走，别写成散文。
2. **每个要点必须"理论 + 材料"**，只写理论或只复述材料都拿不到分。
3. **分点标序号**（①②③），让阅卷老师一眼看到采分点。
4. **宁多勿少**：一般写 4–5 点，多写不扣分。

## 二、通用答题框架

```
【总】材料中 X 老师的做法是正确/错误的，符合/违背了 ××（理论名称）。

【分】
① 理论要点（教材原话）+ 材料中"……"（引用原文）+ 这说明该老师做到了/违背了……

② 理论要点 + 材料 + 结论

③ 理论要点 + 材料 + 结论

④ 理论要点 + 材料 + 结论

【总】综上，教师应……（一句话升华，落到"促进学生发展"上）
```

## 三、按考点分类的答题素材

### 类型 1：考"教学原则"

| 材料情节 | 对应原则 |
|---|---|
| 老师用实物、图片、视频演示 | 直观性原则 |
| 老师提问引导、让学生自己发现 | 启发性原则 |
| 老师按由浅入深顺序讲解 | 循序渐进原则 |
| 老师反复练习、复习旧知 | 巩固性原则 |
| 老师针对不同学生布置不同作业 | 因材施教原则 |
| 老师联系生活实际举例 | 理论联系实际原则 |
| 老师在知识教学中渗透思想教育 | 科学性与思想性相统一 |

**示范表述：**
> ① 材料中王老师运用直观性原则，通过展示实物让学生获得感性认识，符合"让学生通过感官获得直接经验"的要求。
> ② 材料中王老师运用启发性原则，通过提问引导学生独立思考，调动了学生学习的主动性。
> ③ 材料中王老师运用因材施教原则，针对不同基础的学生布置分层作业，做到了从学生实际出发。

### 类型 2：考"德育原则与方法"

| 材料情节 | 对应原则/方法 |
|---|---|
| 老师讲道理、摆事实 | 疏导原则 / 说服教育法 |
| 老师表扬优点、用优点克服缺点 | 依靠积极因素克服消极因素 / 长善救失 |
| 老师既关心又严格要求 | 尊重学生与严格要求相结合 |
| 老师以身作则 | 榜样示范法 / 为人师表 |
| 老师组织实践活动 | 实际锻炼法 / 知行统一原则 |
| 老师创设良好环境、熏陶 | 陶冶教育法 |
| 老师联合家长共同教育 | 教育影响一致性与连贯性 |
| 老师用评比、奖励 | 品德评价法 |

### 类型 3：考"班级管理/班主任工作"

| 材料情节 | 对应理论 |
|---|---|
| 老师选拔培养班干部 | 建立班集体核心队伍 |
| 老师制定班规 | 建立正常秩序 |
| 老师组织班级活动 | 组织形式多样的教育活动 |
| 老师处理突发事件 | 教育性原则、客观性原则、冷处理 |
| 老师转化后进生 | 关爱、发现闪光点、持之以恒 |
| 老师民主管理 | 民主管理原则、学生主体 |

### 类型 4：考"学生心理发展/学习心理"

| 材料情节 | 对应理论 |
|---|---|
| 学生注意力不集中 | 注意规律、无意注意 |
| 学生记不住 | 遗忘规律、过度学习、复习策略 |
| 学生不愿学 | 学习动机、自我效能感、归因 |
| 学生不能举一反三 | 学习迁移、概括化理论 |
| 学生自我中心 | 皮亚杰前运算阶段 |
| 学生需要帮助才能完成 | 最近发展区、支架式教学 |

# 第二部分 教学设计题（1 题，40 分）

> 小学科目二的教学设计题**分学科作答**（语文/数学/英语/音乐/体育/美术等任选其一），
> 通常给一段教材内容 + 3–4 个问题（如：写教学目标、写教学过程、设计板书）。

## 一、标准结构（五段式，照着填）

```
一、教学目标（三维，各 1 条，动词开头）
　　1. 知识与技能：学生能够……（识记/理解/掌握/会……）
　　2. 过程与方法：通过……（朗读/讨论/操作/探究），学生能够……（提高/培养……能力）
　　3. 情感态度与价值观：学生能够体会/感受/养成……（品质/情感）

二、教学重难点
　　1. 重点：本课最核心的知识/技能（一般来自教材标题和基本要求）
　　2. 难点：学生最难理解/最容易出错的地方（一般是情感体会、抽象概念）

三、教学方法
　　讲授法、朗读法、讨论法、情境教学法、直观演示法、练习法（选 3 个）

四、教学过程（四环节，写详案）
　　（一）导入新课（1–2 分钟）
　　　　方式：提问 / 故事 / 图片 / 视频 / 谜语 / 复习旧知
　　　　话术：教师提出……，学生回答……，教师引出课题……（板书课题）
　　（二）新课教学（6–7 分钟，分 2–3 层）
　　　　1. 初读/初步感知：整体感知内容，解决字词/基本概念
　　　　2. 精读/深入研读：围绕重点提问、讨论、品析
　　　　3. 拓展/深化：联系生活、迁移运用
　　（三）拓展延伸（1 分钟）
　　　　设计一个开放性问题或小活动
　　（四）小结作业（1 分钟）
　　　　小结：师生共同总结本课收获
　　　　作业：分层/开放/实践性作业（不要布置抄写十遍这种）

五、板书设计（图示化，简洁）
```

## 二、各学科模板要点

### 语文（最常见）

- **目标**：识字写字 + 朗读 + 体会情感
- **过程**：初读（扫清字词、整体感知）→ 精读（抓关键词句、品析语言、体会情感）→ 拓展（读写结合）
- **常用方法**：朗读法、品词析句法、情境教学法
- **板书**：课文标题 + 结构线索 + 情感主线

**范例（《给予树》）：**

```
教学目标：
1. 正确、流利、有感情地朗读课文，理解重点词句，能用自己的话复述内容。
2. 通过关键词句，联系上下文，体会人物内心情绪变化，提高文章分析理解能力。
3. 感受金吉娅的善良和体贴，培养关爱他人的品质。

教学重难点：
重点：通过关键词句体会金吉娅和妈妈的心情变化。
难点：理解金吉娅善良体贴、富有同情心的美好品质。

教学方法：讲授法、品词析句法、情境教学法。

教学过程：
（一）导入新课
教师提问：中国最隆重的节日是春节，西方国家类似春节的节日是什么？
学生回答：圣诞节。
教师引出课题，板书"给予树"。

（二）新课教学
1. 初读课文，疏通文意：学生用自己喜欢的方式通读全文，思考本文讲了一个什么故事；
   教师巡视指导，重点讲解"沉默不语""如愿以偿"。
2. 品词析句，深入研读：
   （1）划出描写金吉娅的句子，思考她为什么给小女孩买洋娃娃；
   （2）找出体现妈妈心情变化的语句，体会"担心—生气—感动"的变化；
   （3）讨论：妈妈为什么说金吉娅还送给我们善良、仁爱、同情和体贴？

（三）拓展延伸
提问：你觉得"给予树"还是一棵什么树？为什么？

（四）小结作业
1. 抄写自己喜欢的句子。
2. 替那个小女孩给金吉娅写几句感谢的话。

板书设计：
　　　　　　　给予树
　妈妈：担心 → 生气 → 感动
金吉娅：善良　仁爱　同情　体贴
```

### 数学

- **目标**：理解概念/掌握算法 + 经历探究过程 + 体会数学价值
- **过程**：创设情境（生活问题）→ 探究新知（操作、猜想、验证、归纳）→ 巩固练习（分层）→ 总结
- **常用方法**：直观演示法、操作探究法、讨论法、练习法
- **板书**：概念/公式 + 例题 + 易错点

**范例（《圆的周长》）：**

```
教学目标：
1. 理解圆周率的意义，掌握圆的周长计算公式，能正确计算圆的周长。
2. 通过测量、猜想、验证的过程，经历圆周长的探究，提高动手操作与归纳概括能力。
3. 感受数学与生活的联系，体会数学文化（祖冲之）。

教学重难点：
重点：圆的周长计算公式的推导与应用。
难点：理解圆周率的意义。

教学过程：
（一）导入：出示车轮、圆桌，提问"如何知道车轮转一圈走多远"，引出圆的周长。
（二）新课：
　1. 认识周长：摸一摸圆的边缘，明确"围成圆的曲线的长度叫圆的周长"。
　2. 探究关系：小组用绳测法、滚动法测量不同圆的周长与直径，填写表格，
　　 计算周长÷直径的比值，发现比值总在 3 倍多一些。
　3. 归纳公式：介绍圆周率 π≈3.14159…，得出 C=πd 或 C=2πr。
　4. 应用：出示例题，求直径 5cm 的圆的周长。
（三）巩固：分层练习（基础题 + 变式题 + 生活题）。
（四）小结作业：总结公式；作业：测量家中圆形物体的周长。
板书：
　　　　　圆的周长
　C = πd　　C = 2πr
　π ≈ 3.14
```

### 英语

- **目标**：掌握词汇/句型 + 听说读写训练 + 兴趣与文化
- **过程**：Warming-up（歌曲/游戏）→ Presentation（呈现新词句）→ Practice（操练）→ Production（输出运用）→ Summary & Homework
- **板书**：核心句型 + 词汇图

### 音乐 / 体育 / 美术

- **音乐**：导入（听赏）→ 初听感受 → 学唱/分段赏析 → 表现创造 → 小结
- **体育**：热身 → 示范讲解 → 分解练习 → 完整练习 → 游戏比赛 → 放松
- **美术**：欣赏导入 → 观察分析 → 示范技法 → 学生创作 → 展示评价

## 三、拿分细节

1. **三维目标的动词要准确**：知识用"识记/理解/掌握"，过程用"通过……提高……能力"，情感用"体会/感受/养成"。
2. **教学过程要写"师生对话"**，不要只写"教师讲解"——阅卷看的是师生互动。
3. **一定要有板书设计**，哪怕只有三行。
4. **作业要开放**，别写"抄写生字 10 遍"。
5. **时间分配写清楚**（如"约 1 分钟"），显示你有课堂节奏意识。
